

#### 文件分类移动

根据文件名字部分前缀创建子目录, 分类移动到子目录

```py
import os
import shutil
import sys

# dir = r"C:\z_data\1mydata\1min\ani\pic"
dir = input("输入目录名:")

for file in os.listdir(dir):
	if os.path.isdir(os.path.join(dir,file)):
		continue
	print(file)
	# print(file[0:5])
	tmp_dir = f"{dir}/{file[0:5]}".strip(". ")	# 目录首尾不能有空格和.
	os.makedirs(tmp_dir,exist_ok=True)
	shutil.move(os.path.join(dir,file),tmp_dir)
	# break
print("done.")
```
