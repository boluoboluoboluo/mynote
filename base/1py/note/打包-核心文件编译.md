```sh
#原理:
#它将你的 .py 源代码先转换成 C 语言代码，然后再编译成操作系统的二进制机器码
#（Windows 下是 .pyd 文件，Linux 下是 .so 文件）。
#这种文件的逆向难度直接飙升到 C/C++ 级别，极难被破解，且运行速度还会有所提升

```

**1.安装cython:**

`pip install cython`

**2.在项目根目录下创建一个 `setup.py` 编译脚本:**

```py
from setuptools import setup
from Cython.Build import cythonize

setup(
    ext_modules = cythonize("main.py") # 替换为你的核心文件名
)

```

**3.编译:**

`python setup.py build_ext --inplace`

**4.调用:**

`import main` 

编译完成后，你会得到一个 `main.pyd` (Windows) 或 `main.so` (Linux) 文件。此时你**完全可以删掉原始的 `main.py`** ，只要环境里有 Python，用户直接 就能正常调用它。
