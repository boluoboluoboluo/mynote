#### 断言

```sh

# 说明:
-- 断言的核心思想是：“我笃定这里的条件绝对是真，如果是假，说明代码有严重逻辑漏洞，请立刻让程序崩溃。”
-- 程序绝不允许出现的的内部逻辑错误,如果出错,马上抛出异常
-- 断言主要用于单元测试

# 使用
assert 表达式
assert age > 0 	#示例: 断言age>0,如果age的值小于等于0,则程序出错了,马上报错

# 补充

-- 断言主要用于开发环境的调试,快速定位异常
-- 生产环境一般都会关闭,提高性能
	#线上运行时使用:
	python -O main.py	#（大写O）可以全局禁用断言。

```

#### 单元测试

```sh
# 3A 原则:
Arrange : 准备阶段,测试函数,入参,返回等
Action : 执行阶段,执行测试函数
Assert : 断言,判断测试结果

# 测试方法规范:
add()		#示例,假如要测 add 方法
test_add_positive()		# 正常测试
test_add_negative()		# 异常测试


```

**推荐工具 : `pytest` , 安装 : ** 

`pip install pytest` 

编写测试文件 `test_math.py` 

<font color=red>(注意：文件名必须以 `test_` 开头或 `_test` 结尾，函数名必须以 `test_` 开头)</font> 

```py
def add(a, b):
    return a + b

# 纯函数，直接用标准的 assert 断言
def test_add_positive():
    assert add(1, 2) == 3

def test_add_negative():
    assert add(-1, -1) == -2

```

**运行测试 :** 

```sh
# 项目根目录下运行:
pytest		# 会自动疯狂扫描整个项目，找出所有 test_*.py 文件并把里面的测试函数全部跑一遍

pytest -v	# 显示详细执行过程

pytest test_math.py	# 测试特定文件

```
