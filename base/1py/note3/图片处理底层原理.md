

#### 图片缩放

````sh
# 图片放大为例
原图 src_pic(width,height), 目标 dst_pic(dst_width,dst_height) 
比例 scale = width/dst_width
#----------
# 最邻近插值
核心:四舍五入
1.遍历目标图片像素格子	# 如坐标(10,10) ,scale=0.32
2.按比例求出原始像素坐标(浮点数) 	# (3.2,3.2)
3.四舍五入得出原始坐标,取其像素值	# (3,3)
# 伪码:
for (dst_x,dst_y) in (dst_width,dst_height):
	src_x = int(dst_x * scale + 0.5)	# 四舍五入高效写法
	src_y = int(dst_y * scale + 0.5)
	dst_pic[dst_x,dst_y] = src_pic[src_x,src_y]
#缺点:
放大后会出现锯齿,马赛克,色块等

#----------
# 双线性插值
核心:借助原图的上下左右四个像素格子,进行权重计算,得到新的像素值
1.遍历目标图片像素格子	# 如坐标(10,10) ,scale=0.32
2.按比例求出原始像素坐标(浮点数) 	# (3.2,3.2)
3.获取到浮点坐标临近4个格子,以小数为权重,进行插值计算:
	# 几何中心对齐:解决图片在放大或缩小时，画面发生轻微向右下角偏移（漂移）以及边缘颜色不对称的 Bug
	src_x = (dst_x + 0.5) * scale_w - 0.5
	src_y = (dst_y + 0.5) * scale_h - 0.5

	f00 = src_pic[floor(src_x),floor(src_y)]	#左上角 (3,3)
	f10 = src_pic[ceil(src_x),floor(src_y)]		#右上角 (4,3)
	f01 = src_pic[floor(src_x),ceil(src_y)]		#左下角 (3,4)
	f11 = src_pic[ceil(src_x),ceil(src_y)]		#右下角 (4,4)
	ux = src_x - int(src_x)		# 坐标 x 小数部分
	uy = src_y - int(src_y)		# 坐标 y 小数部分
	#计算:
	top_line = (1-ux) * f00 + ux * f10		# 上面2个格子进行一次插值计算
	bottom_line = (1-ux) * f01 + ux * f11	# 下面2个格子进行一次插值计算
	fin_line = (1-uy) * top_line + uy * bottom_line	# 最后上下进行插值计算
	dst_img[dst_x,dst_y] = fin_line
	
#======================
# 图片缩小,同理

# 图片缩小时,采用双线性插值,只能看到 4 个像素,会导致信息丢失,花屏现象
缩小图片时，通常会先用“高斯模糊”把原图大范围的像素融合一下，或者采用多级渐进缩小（图像金字塔），确保每一个像素的能量都被计算进去，而不是只看孤立的 4 个点。

# 高斯模糊:
对每个像素,向其周围半径r的所有邻居借色
1.半径设置大,则邻居越多
	# dt_width,dt_height = (2*r+1, 2*r+1)
	# I 为当前像素,半径为1, 3x3的邻居矩阵
	O O O
	O I O
	O O O
2.利用高斯分布公式,求出每个邻居的权重,然后计算
	G(x,y) = ( 1 / (2*pi*r^2) ) * e^( -(x^2+y^2) / (2*r^2) )	# 高斯分布公式
````

**参考代码: (最邻近插值)** 

```py
from PIL import Image # pip install pillow

img_path = "./test.jpg"

class ImgHandle:
	def __init__(self):
		pass
    # 简单的最邻近插值
	def resize(self,src_img,dst_img,scale):
		src_pixels = src_img.load()
		dst_pixels = dst_img.load()
		for dst_y in range(dst_img.size[1]):
			for dst_x in range(dst_img.size[0]):
				src_x = min(int(dst_x * scale + 0.5),src_img.size[0]-1)	# int(x+0.5) : 和 round(x) 一样,表示四舍五入 
				src_y = min(int(dst_y * scale + 0.5),src_img.size[1]-1)
				dst_pixels[dst_x,dst_y] = src_pixels[src_x,src_y]
def main():
	src_img = Image.open(img_path)
	src_width,src_height = src_img.size
	scale = 0.3
	dst_w,dst_h = int(src_width/0.3),int(src_height/0.3)
	dst_img = Image.new('RGB', (dst_w, dst_h))
	handle = ImgHandle()
	handle.resize(src_img,dst_img,scale)
	dst_img.save("dst.jpg")

if __name__ == "__main__":
	main()
```

#### 图片旋转

```sh
#说明
1.图片之间旋转后的坐标为浮点数,不能直接填充,四舍五入也会导致图片错乱
2.应该根据目标像素格子,逆旋转,得出原图片像素坐标,然后使用线性插值法

#旋转公式: 设 _u 为旋转角度
x2 = x*cos_u + y*sin_u
y2 = -x*sin_u + y*cos_u
#逆旋转公式:
x = x2*cos_u - y*sin_u
y = x2*sin_u + y*cos_u

#关于新画布大小:
1.当图片旋转 45 度时，由于四个角向外凸起，新图的宽高会比原图更大。如果依然申请和原图一样大的内存，图片的四个角就会被切掉。
2.旋转时,如果长宽比不一样,矩形画布大小同样需要调整
width2 = width*cos_u + height*sin_u
height2 = width*sin_u + height*cos_u

#关于旋转坐标问题:
1.旋转时,不是以坐标(0,0)旋转,而是以图片中心旋转,所以需要调整坐标中心
2.坐标平移公式:
	坐标系原点平移：把目标图的当前坐标 (x2,y2) 平移，将原点暂时挪到目标图的中心
	假设 (x0,y0) 为原图中心坐标
	x2 = x2 - x0
	y2 = y2 - y0
3.根据逆旋转公式计算坐标 (x,y)
4.坐标系还原:将原图中心系下的坐标，重新平移回原图以左上角为标准的标准坐标系
	x = x + x0
	y = y + y0
```
