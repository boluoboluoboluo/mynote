#### 向量点积

```sh
# 向量 
A = (1,0)
B = (0,1)
AB = A + B = (1,1)

# 向量点积:向量 A 的长度在向量 B 上的投影(夹角cosAB,并以B为单位拉伸)
# 向量点积的结果为标量
A · B = |A| * |B| * cosAB = A.x * B.x + A.y * B.y
A · B = A.x*B.x + A.y*B.y + A.z*B.z		#三维空间

# 垂直的向量,点积为0

# 向量点积
在物理上表示做功的效率
在几何空间表示方向,投影,能计算夹角,判断前方后方,是否垂直
在计算机里表示匹配度,权重,重合度等

# 点积满足交换律
A · B = B · A
```

#### 向量叉积

```sh
# 向量叉积一般表示三维空间
# 向量叉积的结果,生成一个同时垂直于这两个向量的第三个向量
# 伸出右手，四指从 A 弯曲指向 B，大拇指所指的方向就是叉积向量 C 的方向

# 叉积是一个只属于“低维空间”的魔术。2维和3维可以算，但4维及以上在严格数学上是没有叉积的,计算会报错
(1,2) 和 (3,4) 的叉积	# 叉积为标量
(1,2,3) 和 (4,5,6) 的叉积	# 叉积为 新3维向量
(1,2,3,4) 和 (5,6,7,8) 的叉积	# 无法计算

# 为什么 2D 叉积是个数字，而 3D 是个向量
 -- 数学家为了方便故意设计的

==============
# 叉积计算方程:
C = A x B
C.x = A.y * B.z - A.z * B.y
C.y = A.z * B.x - A.x * B.z
C.z = A.x * B.y - A.y * B.x

# 上述计算过程,可用矩阵行列式计算

# 三维空间叉积作用
1.计算平面法向量（3D 渲染与光照的核心）
2.构建 3D 坐标系
3.计算 3D 空间中的转动（力矩、角速度、旋转轴）
4.3D 空间中的精确面积与碰撞检测
==============
# 二维空间
A.z = 0 , B.z = 0
带入公式:
C.x = A.y * 0 - 0 * B.y
C.y = 0 * B.x - A.x * 0
C.z = A.x * B.y - A.y * B.x
# 所以,二维空间的叉积是一个标量
C.z > 0  :向量 B 在向量 A 的逆时针方向（左侧） 
C.z < 0  :向量 B 在向量 A 的顺时针方向（右侧）
C.z = 0  :两向量共线（平行或重合）
# 模长 (叉积的绝对值)
模长: |A x B| = |A| * |B| * sinAB	#表示组成平行四边形的面积
模长/2 :表示组成三角形的面积

# 二维叉积作用
1.判断 B 在 A 的左边还是右边（拐弯方向）
2.计算三角形/平行四边形面积
3.判断两个线段是否相交
	-- 看线段的端点是否分别在另一条线段的左右两边
4.判断点是否在三角形内部
==============


# 叉积不满足交换律
A · B = -(B · A)
```
