

#### 碰撞类型

```sh
# 盒状包围体
1.AABB（轴对齐包围盒）
	-- 特点：矩形永远保持水平和垂直，不能旋转
	-- 场景：2D俯视角游戏（不旋转的坦克、地图障碍物）、2D平台跳跃（马里奥）
2.OBB（有向/旋转包围盒）
	-- 特点：矩形可以随物体任意角度旋转
	-- 场景：允许原地转弯的坦克、3D车辆载具、旋转的障碍物
	
# 基础数学几何体
1.球体/圆形包围盒(Sphere/Circle)
	-- 特点：只需中心点和半径。性能极高（业界第一）
	-- 场景：游戏子弹、爆炸范围判定、格斗游戏的打击框（Hitbox）
2.胶囊体(Capsule)
	-- 特点：一段线段外加半径。底部是圆弧，移动时不易被地形直角卡住
	-- 场景：3D游戏里绝大多数的人类角色、NPC和怪物

# 不规则与高精度体
1.凸多面体(Convex)
	-- 特点：没有任何凹陷的不规则多面体。可以使用高效数学算法的最复杂形状
	-- 场景：3D碎石、复杂的箱子、车辆底盘
2.凹多面体/网格碰撞体(Mesh)
	-- 特点：直接使用3D美术模型。精度最高，但计算量恐怖，绝不允许两个网格互撞
	-- 场景：静态的3D大地图、复杂的建筑物墙体
3.复合包围盒(Compound)
	-- 特点：用多个基础形状（如几个 AABB 或球体）拼接出的复杂组合体
	-- 场景：既要性能又要精度的复杂物体（例如：车身用OBB + 炮管用胶囊体）
	
# 线与点探测（Ray-based）
1.射线投射(Raycast)
	-- 1条从起点出发、有方向、无限或有限长的线。用于即时命中枪械、视线判定
2.像素级碰撞
	-- 2D游戏特有。重叠时对比像素透明度（Alpha值），极度消耗性能，现代少用2D游戏特有。重叠时对比像素透明度（Alpha值），极度消耗性能，现代少用
```

##### 分轴法(ai)

```sh
# 解决偶尔抽搐和画面不流畅,抖动
# 彻底解决斜向运动、同向追尾、多物体交叉重叠等所有复杂的碰撞抽搐问题，而且代码会变得极其简单，完全不需要判断谁在前谁在后，也不需要用 clip 计算重叠矩形

# 分轴运动法
把 X 轴和 Y 轴的移动完全拆开，各走各的，分别检测

# 执行流程
1.轮到某个物体的 update 时:
	-- 先只在 X 轴移动,立刻检测 X 轴碰撞(遍历 group 所有成员),撞到了就立刻把 X 坐标退回边缘
	-- 再在 Y 轴移动,立刻检测 Y 轴碰撞(遍历 group 所有成员),撞到了就立刻把 Y 坐标退回边缘
	

```

##### 分轴法代码

```py
def update(self,dt,screen_rect,keys):
    # pos坐标更新
    self.pos += self.direction * self.speed * dt
    # 是否碰撞标志
    is_hit = False
    #--------------------------------------------start
    # 分轴法,先移动 x轴 再移动 y轴,分别检测
    # 如果 x轴 方向的速度,则移动 x坐标并检测
    if self.direction.x != 0:
        self.rect.x = round(self.pos.x)	# 移动
        obj = self.check_collide()
        if obj:	# 如果碰撞
            is_hit = True
            if self.direction.x > 0:	# 如果 方向>0,则回退, 自己 右侧 与对方 左侧 贴合
                self.rect.right = obj.rect.left 
            else:
                self.rect.left = obj.rect.right
            self.pos.x = self.rect.x 	# pos同步更新
    # y轴方向速度,则	移动 y坐标并检测
    elif self.direction.y != 0:
        self.rect.y = round(self.pos.y)	# 移动
        obj = self.check_collide()
        if obj:	# 如果碰撞
            is_hit = True
            if self.direction.y > 0:	# 如果 方向>0,则回退, 自己 底部 与对方 顶部 贴合
                self.rect.bottom = obj.rect.top 
            else:
                self.rect.top = obj.rect.bottom
            self.pos.y = self.rect.y	# pos同步更新
    else:
        pass
    #--------------------------------------------end
    # 如果没碰撞, 执行边界检测并更新坐标
    if not is_hit:
        min_x, max_x = 0, screen_rect.width - self.rect.width
        min_y, max_y = 0, screen_rect.height - self.rect.height
        # 边界检测
        if self.pos.x < min_x or self.pos.x > max_x or self.pos.y < min_y or self.pos.y > max_y:
            self.rand_direction()
        self.pos.x = max(min_x,min(self.pos.x,max_x))
        self.pos.y = max(min_y,min(self.pos.y,max_y))
        # 更新坐标
        self.rect.topleft = (round(self.pos.x), round(self.pos.y))
```
