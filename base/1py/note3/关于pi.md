# 旋转与投影
# 假设匀速运动的摩天轮上有一个发光的座舱（我们就叫它红灯）,竖着方向观察它
1.当红灯转到最顶部时，它正准备往下走，在这一瞬间，它在垂直方向上是静止的。
2.随后，红灯开始往下掉，它的下落速度越来越快
3.当它经过最中间（和轴心等高）的那一刹那，它的下落速度达到了最快
4.过了中间点后，它开始减速，下落得越来越慢
5.直到掉到最底部，它又静止了一瞬间，准备往上走

# 秋千运动
1.在最高点，秋千静止了一瞬间，然后开始往下荡，速度越来越快
2.荡到最正中间（最低点）时，秋千的速度达到了最快
3.冲过最低点后，秋千开始往另一边高处荡，速度越来越慢。
4.到达另一边的最高点，再次静止

# 根据上面例子,为了表达红灯影子和秋千的运动快慢的规律
# 我们规定点在圆上做匀速圆周运动,在坐标系的投影为正弦波
# 波随时间变化与y轴的距离变化,即可表示运动的快慢程度
# 怎么计算这个波呢 (也就是计算具体的快慢变化过程)
数学家在计算秋千的运动时，发现秋千这种"两头慢、中间快"的节奏，在数学上和摩天轮高度变化的节奏完全同步
1.圆匀速运动,角度也是匀速变化的,不同角度投影的运动速度不一样
2.科学家把'时间'变成'角度'
3.因为单位圆运动一圈为'360°',弧度为'2pi',所以又把'角度'变成'弧度'
# 科学家强行在秋千的公式里引入了pi
角度 -> 弧度 -> 投影运动 	# 映射:圆匀速运动和投影运动

# pi 和 三角函数
# 为了测量角度变化时,投影的精确高度,希腊人发明三角函数
sinʘ  表示圆转到角度 ʘ 时,投影的高度/圆半径
	-- 但是，如果用"度"（如30度、90度）来计算，在高级数学里会遇到一个巨大的麻烦：
	-- "度"是人类一厢情愿规定的（为什么一圈是360度？因为一年大概365天，古人为了好平分强行规定的，它不是宇宙自然的规律）
	-- 为了让大自然的公式最纯粹，数学家抛弃了"度"，改用圆的天然属性——"弧度"
	-- 半径为1,那么弧长就是2pi

# 三角函数 sinʘ 的计算:
sinʘ = 投影高度/半径
	-- 当 ʘ 很小时,投影高度 ~= 弧度 => sinʘ ~= ʘ
	-- 当 ʘ 变大时,投影高度变化 和 弧度的关系,满足一个规律	# 泰勒公式的推导
		-- (ʘ - sinʘ) 和 ʘ 的三次方 ʘ^3 成正比: sinʘ ~= ʘ - ʘ^3/6
	-- ʘ 继续变大,投影高度变化需要继续修正,由此得出最终公式:
		sinʘ = ʘ - ʘ^3/3! + ʘ^5/5! - ʘ^7/7! + ...		# 泰勒展开
		
# 泰勒思想:
如果一个曲线很难算，那我就在某个点上，造一个由‘加减乘除’组成的代数多项式，去疯狂地模仿这条曲线。
如果它们在这一点的所有变化趋势都一模一样，那它们就必然是同一条曲线！
	# 变化趋势:导数
	原函数 sinʘ：代表当前红灯的高度位置。
	1次导数（求导1次）：代表高度变化的速度
	2次导数（求导2次）：代表高度变化的加速度（速度改变快慢）
	3次导数（求导3次）：代表加速度的变化率……以此类推
	
# sinʘ 的取代计算:
	# 位置：sin0 = 0	的变化趋势:
	速度：sin 的导数是 cos，cos(0) = 1
	加速度：cos 的导数是 -sin，-sin(0) = 0
	3次变化率：-sin 的导数是 -cos，-cos(0) = -1
	...
	# 取代:
	我们假设: f(ʘ) = A + Bʘ
	要让起点位置等于 0，代入 ʘ=0 ，得到 A = 0
	要让起点速度等于 1，对它求导得到 B，所以 B = 1
	得到: f(ʘ) = A + Bʘ
		-- 由于 f(ʘ) = A + Bʘ 的加速度永远是 0，而 sinʘ 的 3 次变化率是 -1	# 所以不满足
	为了保持变化趋势,引入:f(ʘ) = A + Bʘ + Cʘ^2
	...
	无限模仿变化趋势,得到最终公式:
		f(ʘ) = ʘ - ʘ^3/3! + ʘ^5/5! - ʘ^7/7! + ...
		
	
# sin的导数为什么是cos:
sinʘ 的导数,代表投影高度的变化率,即表示垂直方向的速度
直观感受: 当 ʘ = 0 时,垂直方向速度最大,当 ʘ = pi/2 时,高度到达最高,开始下落,此时垂直方向速度达到最小值0
微观: 当 ʘ ~= 0 时,水平速度为0,垂直速度=圆运动速度=1
当 ʘ 变化时,垂直速度和运动速度的角度也是 ʘ ,垂直速度/运动速度 = cosʘ 
所以 sinʘ' = cosʘ 
同理求出 cosʘ' = -sinʘ

# 初始相位
只有知道了'初始相位'(即'初始弧度'),根据'时间'和'频率'计算出的'弧度'再计算'垂直高度',才有意义
	-- 基站为了让你的手机知道波的'初始位置'，它在发送真正的视频或文字数据之前，会先发射一段长得很特殊的、所有芯片都提前知道的'标准波'。
	   这段波就像是跑步比赛前的'各就各位'
	-- 手机天线一听到这段熟悉的'标准波'，芯片就会立刻调整自己的内部时钟
	-- 比如，芯片发现这段标准波的波峰在自己内部时钟的第 1.2 纳秒到达了，芯片就会立刻进行'对齐'校准：把这个时刻强行定义 pi/2
	-- 确定'初始位置'这个过程在通信里叫做'定时同步'和'载波相位同步'

	-- 基站发射信号时，它不是只发射一个波，而是同时发射两个频率一模一样、但位置刚好错开 1/4 圈（也就是错开 pi/2）的波
	-- 一个是正弦波 (对应'sin',也就是高度)
