#### 思路

```sh
#画直线原理:
初始坐标(0,0),(dx,dy)
斜率:k = dy/dx

设当前坐标为(x,y)
#分2种情况讨论:
#1.当 k<1 时,即斜线小于45度时,此时坐标x每次加1,y可能为y,也可能为y+1,即y的每次增长不会超过1
	(x,y) 的下一坐标为 :
	(x+1,y+1)	# 直线上方
	(x+1,y)		# 直线下方
	坐标 (x+1,y+1) 的斜率 k1 = y/(x+1)
		与标准斜率k的差值:
		d1 = (y+1)/(x+1) - k 	# 这个数 > 0
	同理(x+1,y) 的斜率 k2 = y/(x+1):
		d2 = y/(x+1) - k 		# 这个数 < 0
	d1 + d2 = (2*y+1)/(x+1) - 2*k
	如果 d1 + d2 > 0 ,下一坐标取 (x+1,y),否则取 (x+1,y+1)
		d1 + d2 > 0 得:
		(2*y+1)/(x+1) - 2*dy/dx > 0, 化简得:
		dx*(2*y+1) - 2*dy(x+1) > 0
	设 p = dx*(2*y+1) - 2*dy(x+1)
	p > 0 则取坐标 (x+1,y)
	p < 0 则取坐标 (x+1,y+1)
	# p即为判断得关键

	#由于 p = dx*(2*y+1) - 2*dy(x+1) 这个表达式不好直观判断,我们引入 p的增量q 概念
	#p>0 时:
		坐标取 (x+1,y),带入表达式 dx*(2*y+1) - 2*dy(x+1) ,此时可计算p2:
		p2 = dx*(2*y+1) - 2*dy(x+2)
		q = p2 - p = -2*dy
		即:
		p2 = p - 2*dy
	#p<0 时:
		坐标取 (x+1,y+1),带入表达式 dx*(2*y+1) - 2*dy(x+1) ,可计算p2:
		p2 = dx*(2*y+3) - 2*dy(x+2)
		q = p2 - p = 2*dx - 2*dy
		即:
		p2 = p + 2*dx - 2*dy

	(0,0)时,初始的 p = dx - 2*dy
	由此,可以进行递推判断

#2.当 k>1 时,即斜线大于45度时,此时坐标y每次加1,x可能为x,也可能为x+1,即x的每次增长不会超过1
	(x,y) 的下一坐标为 :
	(x,y+1)		# 直线上方
	(x+1,y+1)	# 直线下方

	此时x,y轴对调,即x=y, y=x,和上面得情况一样了,可得:
	p = dy*(2*x+1) - 2*dx(y+1)
	p > 0 则取坐标 (x,y+1)
	p < 0 则取坐标 (x+1,y+1)
	# p即为判断得关键
	p > 0时:
		取坐标 (x,y+1)
		q = p2 - p = -2*dx
		p2 = p - 2*dx
	p < 0时:
		取坐标 (x+1,y+1)
		p2 = p + 2*dy - 2*dx

	初始 p = dy - 2*dx
	由此,可以进行递推判断
```

#### 代码

```py
import tkinter as tk
from PIL import Image, ImageTk	#pip install pillow

#布雷森汉姆（Bresenham）画直线算法
#pillow写内存数据,Tkinter 弹窗

width=500
height=500
# 申请一块连续的内存（RGB彩色画布，初始全为黑色）
# Pillow 内部会分配 width * height * 3 字节的连续 RAM 空间
img = Image.new("RGB", (width, height), color=(0, 0, 0))

# 获取这块内存的直接操作指针（像素访问对象）
# 对 pixels[x, y] 的赋值会直接改写底层对应的 3 个字节
pixels = img.load()

# 设定线条颜色（金色）
line_color = (255, 215, 0)

# 中心坐标
zx = 10
zy = 20

#直线初始坐标
x=0
y=0

#直线结束坐标
dx=100
dy=300

#填充像素数据
def draw(x,y):
	pixels[x+zx,height-zy-y] = line_color

# 画直线,斜率k<1时
def drawline(x,y,dx,dy):
	p = dx - 2*dy
	while x <= dx:
		draw(x,y)
		if p > 0:
			p = p -2*dy
		else:
			y = y + 1
			p = p + 2*dx - 2*dy
		x = x + 1
# 画直线,斜率k>1时
def drawline2(x,y,dx,dy):
	p = dy - 2*dx
	while y <= dy:
		draw(x,y)
		if p > 0:
			p = p -2*dx
		else:
			x = x + 1
			p = p + 2*dy - 2*dx
		y = y + 1

if dy > dx:	#斜率k>1时
	drawline2(x,y,dx,dy)
else:
	drawline(x,y,dx,dy)

#  初始化 Tkinter 窗口
root = tk.Tk()
root.title("直线")

#  【核心转换】将 Pillow 的内存数据包装成 Tkinter 能看懂的图片格式
# 这一步相当于把内存里的像素打包，准备往显存和窗口总线里运送
tk_image = ImageTk.PhotoImage(img)

# 用简单的 Tkinter 标签（Label）来装载这幅画
label = tk.Label(root, image=tk_image)
label.pack()

# 启动窗口事件循环（让窗口保持显示，等待操作系统刷新显存）
root.mainloop()
```
