#### 思路

```sh
# 1.已知圆八边对称,只需要1/8圆弧的位置,就能知道其他位置
# 2.假设圆心坐标(0,0),我们先画(0,r)y轴右边45°的圆弧
# 3.根据当前坐标(x,y),下一坐标可能是(x+1,y),或者(x+1,y-1),判断这2个坐标哪个离圆弧距离更近,就用哪个坐标

(x+1,y)坐标与圆弧距离差值:	# 这个坐标在圆弧外部
	d1 = (x+1)^2 + y^2 - r^2 			# d1 > 0
(x+1,y-1)坐标与圆弧距离差值:	# 这个坐标在圆弧内部
	d2 = (x+1)^2 + (y-1)^2 - r^2 		# d2 < 0
然后这两个差值相加:
	p = d1 + d2
	p = 2*x^2 + 2*y^2 + 4*x - 2*y + 3 - 2r^2
	如果p>0,则说明(x+1,y-1)离圆弧更近,取该坐标为下一坐标
	如果p<0,则说明(x+1,y)离圆弧更近,取该坐标为下一坐标
	
# p就是判断的关键,根据p就可以判断确定下一个坐标
# 由于 p = 2*x^2 + 2*y^2 + 4*x - 2*y + 3 - 2r^2 ,该算式过于复杂,不好每次判断和计算:
# 我们引入p的增量q的概念
我们继续算,后续坐标p2:
由前面可知:
如果p > 0,下一个坐标取(x+1,y-1),那么
	p2 = 2*(x+1)^2 + 2*(y-1)^2 + 4*(x+1) - 2*(y-1) + 3 - 2*r^2
假设它们之间增量为q: 
	q = p2 - p
	q = [2*(x+1)^2 + 2*(y-1)^2 + 4*(x+1) - 2*(y-1)] - [2*x^2 + 2*y^2 + 4*x - 2*y]
	q = 4*x + 2 - 4*y + 2 + 4  + 2
	q = 4*x - 4*y + 10
如果p <= 0,下一个坐标取(x+1,y),那么
	q = p2 - p
	带入计算可得:
	q = 4*x + 6

# 此时,我们回到第一步,当坐标为(0,r)时,计算最初始的p:
	p = 2*x^2 + 2*y^2 + 4*x - 2*y + 3 - 2r^2
	代入可得:
	p = 3 - 2*r

由前面可知,根据p的值,即 p>0还是p<0,
	可以判断下一个坐标
	也可以得出p的下一次的增量q
	根据增量q,又可以判断下一次的p2
	p2 = p + q
# 此时就可以递推判断了
```

#### 代码

```py
import tkinter as tk
from PIL import Image, ImageTk		#pip install pillow

#布雷森汉姆（Bresenham）实心圆算法
#pillow写内存数据,Tkinter 弹窗

width=500	#窗口宽度
height=500
# 申请一块连续的内存（RGB彩色画布，初始全为黑色）
# Pillow 内部会分配 width * height * 3 字节的连续 RAM 空间
img = Image.new("RGB", (width, height), color=(0, 0, 0))

# 圆心坐标
cx = 250
cy = 250

# 获取这块内存的直接操作指针（像素访问对象）
# 对 pixels[x, y] 的赋值会直接改写底层对应的 3 个字节
pixels = img.load()

# 设定圆的颜色（金色）
circle_color = (255, 215, 0)

r = 100		#半径
#初始坐标
x=0
y=r

p = 3 - 2*r		#初始p值

#画圆的边缘,填充像素数据
def draw(x,y):
	pixels[x+cx,cy-y] = circle_color

while x <= y:	
	draw(x,y)
	draw(x,-y)
	draw(-x,y)
	draw(-x,-y)
	draw(y,x)
	draw(y,-x)
	draw(-y,x)
	draw(-y,-x)
	
	if p > 0:
		y = y-1
		p = p + 4*x - 4*y + 10
	else:
		p = p + 4*x + 6
	x = x+1

#  初始化 Tkinter 窗口
root = tk.Tk()
root.title("圆")

#  【核心转换】将 Pillow 的内存数据包装成 Tkinter 能看懂的图片格式
# 这一步相当于把内存里的像素打包，准备往显存和窗口总线里运送
tk_image = ImageTk.PhotoImage(img)

# 用简单的 Tkinter 标签（Label）来装载这幅画
label = tk.Label(root, image=tk_image)
label.pack()

# 启动窗口事件循环（让窗口保持显示，等待操作系统刷新显存）
root.mainloop()
```
