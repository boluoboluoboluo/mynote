

```sh
# 概念
1.e 叫"自然常数"（约等于 2.718），它的本质代表了宇宙中"最完美的利滚利（复利）"。
2.这个数字不是谁凭空发明出来的，而是由数学家'雅各布·伯努利'在算账、研究银行高利贷时死磕出来的。

#------------
# 推导
# 假设你把 1 块钱存进银行，银行非常大方，承诺年利率 100%。
1.情况 A（一年结一次账）：
	到年底，你本金 1 块 + 利息 1 块 = 2 块钱。
2.情况 B（半年结一次，利滚利）：
	半年时你有利率 50%，本息变成 1.5 块。
	下半年这 1.5 块继续滚 50% 利息。
	年底变成: 1 * (1+0.5)^2 = 2.25 块钱。
3.情况 C（按月结账，利滚利）：每个月利率是 1/12，
	年底变成 (1+1/12)^12 ~= 2.61 块钱。
	
# 伯努利当时就想：如果银行疯了，每分、每秒、甚至无穷小的时间都在无限进行利滚利呢？我是不是能变成世界首富，拿到无限多的钱？
	#极限公式:
	lim(1+1/n)^n	# n -> 无穷
# 见证奇迹的时刻：他算到最后发现，即便 n 变成一亿、一万亿（无限连续复利），最后存进去的 1 块钱也无法突破一个天花板，它会无限逼近 2.7182818...

# 因为大自然中所有事物的生长（比如细胞分裂、细菌繁殖、放射性物质衰变）都是这种无时无刻不在发生的、连续的、自然的“利滚利”或衰变，所以它被叫做“自然常数”。例如在高斯模糊里，它就负责提供那种最平滑、最符合自然规律的平滑衰减。
```

```sh
# e 的应用
# 关于细菌细分的例子
假如细菌每小时分裂 1 次,那么 13 小时后数量是多少
	直觉: 2^13 = 8192
	##实际上:
	细菌每小时分裂1次, 利率 100%
	半小时算的话,分2次,利率50%
	得出1小时之内,任意瞬间分裂计算:
		(1+1/n)^n	# 也就是e
	对应自然界现象,细菌无时无刻都在分裂的可能
	实际结果: e^13 = 442413
#===============
# 特别说明:
上面的例子,细菌以及银行家,都默认增长率为1的情况下
如果一个细菌严格在 1 小时内刚好变成了 2 倍，那么它在这 1 小时里的瞬时增长率 r 其实是 0.693（小于1）
# 如果增长率不是1,那么结果就随着增长率变化
	细菌增长的公式: e^(r*t)		# r为增长率
# 解释:周期内,增长的极限是e,如果增长率改变,就不是e了
比如,细菌1小时后分裂成3个
# 增长率和e对齐
如果周期内增长e倍,增长率为1
如果增长e^2倍,增长率为2
...

# 增长率的意义
# 引入增长率 r，就是为了打破人类死板的时间单位，去精确锚定各个事物自身“翻 e 倍所需的专属增长周期”。
1.增长率是为了确定增长极限为 e 时的那个增长周期
2.如果某个周期内,极限为e,那么增长率就是1,不过后续的时间都要按那个周期计算
3.实际上我们先确定了周期,比如按小时计算,如果59分钟一个周期,那10个小时后增长多少呢
为了方便控制周期,引入增长率计算
4.增长率就是周期的倒数
	假设10小时翻e倍,但是我们按小时算,所以 r=1/10
	假设0.5小时翻倍,我们周期按小时算,所以 r=2
```
