```sh
# 矩阵与矩阵的乘法 (点积)
条件: 前一个矩阵的列数必须等于后一个矩阵的行数
	-- 即 m x n 的矩阵只能与 n x p 的矩阵相乘，结果是一个 m x p 的新矩阵
意义: 
	示例,复合空间变换:
	-- 如果矩阵 A 代表'顺时针旋转 30 度'，
	-- 矩阵 B 代表'在 X 轴方向拉伸 2 倍'
	-- 矩阵乘法 A X B 得到的新矩阵，就代表'先拉伸、再旋转'的连续组合变换	
	
-----------------------
# '除法': (逆矩阵)
# 逆矩阵概述:
算法:
	-- 在矩阵中，如果矩阵 A 乘以矩阵 B 等于单位矩阵 I（主对角线全为 1、其余全为 0 的矩阵）
	   那么 B 就是 A 的逆矩阵，记作 A^-1
	-- 类比 数学除法: 5 x 1/5 = 1
	-- 示例,求Y:
		A x Y = B	=> Y = A^-1 x B
		Y x A = B 	=> Y = B x A^-1
	
意义:
	-- 变换的逆向恢复（撤销操作）:
	   如果矩阵 A 代表'向东移动 5 米并旋转 90 度'，那么它的逆矩阵 A^-1 就代表'旋转 -90 度并向西移动 5 米'
	-- 求解线性方程组 ?
# 注意 :
只有方阵（行数等于列数）才可能拥有逆矩阵，并且该方阵的行列式不能为 0（行列式为 0 的矩阵叫'奇异矩阵'，类似于数字 0 没有倒数一样）



```

#### 内积外积

```sh

# 乘法 = 内积
# 代表 投影与相关性
算法: 左边矩阵的行，去和右边矩阵的列分别做'点积'，然后拼成新矩阵
 -- 左边的行可以理解为 基本元素
 -- 右边的列 行的子元素对应的列的子关系
 -- 点积结果: [0,1]	# 表示第0行所有元素,与第1列对应子关系的加成总和

======================
# 关于矩阵 叉积
# 叉积 (Cross Product) / 向量积
# 只对 2D 或 3D 向量有效, 2D 算出来是数字(面积), 3D 算出来是一个新向量(法线)
 -- 在严格的数学上，矩阵（二维或更高维数组）是没有“叉积”这一说的
 -- 写代码的人把'矩阵的克罗内克积（Kronecker Product）'或'外积（Outer Product）'错误地口误说成了'叉积'
 -- 在 NumPy 中，如果你对两个矩阵做 np.cross(A, B)，NumPy 并不是在算矩阵的叉积，而是把矩阵拆成了'一堆一维向量'
 -- 示例:
 	-- A 是一个 100 行 3 列的矩阵（代表 100 个 3D 向量）
 	-- B 也是 100 行 3 列。
 	-- np.cross(A, B) 会把它们一行一行对应做 3D 叉积，最后吐出一个 100 行 3 列的结果
 
======================
# 外积 (Outer Product)
# 注意: 这是最容易和'叉积（Cross Product）'搞混的概念！英文完全不同
算法: 第一个向量的每一个数字，去乘以第二个向量的整排数字，排成一个表格
 	a = [1,2]	# 基本元素
 	b = [3,4]	# 关系
 	a.outer(b) 
 	= [
 		[1x3,1x4],
 		[2x3,2x4]
 	  ]
结果: 一个矩阵（二维表格）	# 表示 元素 和 关系 的结构存储 (信息)

```

```sh
# 转置
算法: 把矩阵的行和列互换
意义:
	-- 改变观察数据的视角
	-- 公式推导的工具
	
# 行列式 
算法: 只针对方阵（行数=列数）计算，结果是一个缩放比例（标量数字）
意义:
	-- 空间体积的缩放倍数
	-- 如果行列式等于 0，说明这个变换把二维面积压缩成了一条线，或者把三维体积压缩成了一个面（降维了，信息丢失），
	   因此这个矩阵不可逆
	   
# 迹 (Trace)
算法: 只针对方阵，把主对角线（左上角到右下角）上的所有元素加起来
意义: 
	-- 在几何上，它与矩阵变换后的'总拉伸量'有关
	-- 在机器学习中，常用于简化矩阵求导的公式，或者作为一种衡量矩阵大小的指标

-----------------------
# 特征值与特征向量 
定义:
	-- 对于方阵 A，如果能找到一个向量 V 和一个数字 r，使得:
		A x V = r x V
	-- 那么, V 就是特征向量,r 就是特征值
意义:
	-- 通常，矩阵乘以一个向量，会把向量既旋转又拉伸
	-- 如果把矩阵乘以它的'特征向量'，这个向量完全不发生旋转，只是在原方向上被纯粹地拉伸（或缩短）了 r 倍
应用:
	-- 网页算法 ?
	-- 桥梁振动分析 ?

# 矩阵分解

# 奇异值分解 
含义: 任何矩阵（不一定是方阵）都可以分解为三个特殊矩阵的乘积,其中包含旋转、缩放、再旋转
应用:
	-- 图像压缩: 只保留最重要的几个奇异值，可以把一张几兆的图片压缩到几十KB，且肉眼看不出明显区别
	-- PCA降维: 在数据科学中，把几百个维度的复杂数据，压缩到 2-3 个核心维度，方便可视化
	-- 推荐系统: 视频平台推荐算法等
	
#  LU 分解 / QR 分解

应用:
	-- 计算机解方程的加速器
```
