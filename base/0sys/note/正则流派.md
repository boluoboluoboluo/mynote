

```sh
# 说明:
两大正则流派：基础正则 (BRE) 和 扩展正则 (ERE)。它们的转义规则刚好完全相反


# 流派 A：基础正则表达式 (BRE) —— grep、sed
# 在默认的 grep 和 sed 中，为了保护普通的 ?、+、()、{} 不被频繁转义，它们把规则反过来了：普通符号直接代表文本；想要特殊功能，反而要加反斜杠！
直接写代表文本本身，加了反斜杠才变特殊功能:
	# 示例:
	? 匹配问号本身；\? 才代表出现 0 或 1 次
	+ 匹配加号本身；\+ 才代表出现 1 次以上
	() 匹配括号本身；\(\) 才代表分组
	{} 匹配大括号本身；\{\} 才代表指定次数


# 流派 B：扩展正则表达式 (ERE) —— egrep、grep -E、sed -r、awk
# 这个流派的规则就和 Python、JavaScript 等大部分语言完全一样了
必须转义才能匹配文本本身：
\*
\+
\?
\.
\| 和 \\
\^ 和 \$
\( 和 \)
\[ 和 \]
\{ 和 \}
```
