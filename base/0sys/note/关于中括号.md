#### 关于[[]]和[]

**`[[ ]]` 的本质：** 它其实是一个专门用来做“比较”或“测试”的**命令**

```sh
#if 语句并不只看 true 或 false，它看的是 命令的退出状态码(Exit Status)
在 Shell 中，任何命令都可以直接跟在 if 后面
只有当你需要进行“逻辑比较”（大小、相等、正则、文件属性）时，才需要请出 [[ ]] 这个特殊的“测试工具”来帮忙
```



如果你编写的是 **Bash** 脚本（开头是 `#!/bin/bash`），**请永远优先使用 `[[ ]]`**

| 特性         | `[ ]` (test 命令):标准测试       | `[[ ]]` (Bash 关键字):扩展测试           |
| :----------- | :------------------------------- | :--------------------------------------- |
| **兼容性**   | **极高**（所有 POSIX sh 都能用） | 一般（Bash, Zsh, Ksh 可用）              |
| **安全性**   | 容易因为变量为空或带空格报错     | **非常安全**                             |
| **模式匹配** | 不支持                           | **支持 `\*` 和正则 `=~`**                |
| **逻辑运算** | 使用 `-a`, `-o`                  | 使用 `&&`, `                             |
| **数学比较** | 使用 `-gt`, `-lt` 等。           | 依然使用 `-gt` 等，但在 `(( ))` 中更好用 |

```sh
#模式匹配示例
file="backup_2026.log"
if [[ $file == *.log ]]; then
    echo "这是一个日志文件"
fi
```

```sh
#正则匹配示例 =~
phone="13812345678"
if [[ $phone =~ ^1[3-9][0-9]{9}$ ]]; then
    echo "手机号格式正确"
fi
```

```sh
#逻辑比较示例
# [[ ]] 的写法 (清晰直观)
if [[ $a -eq 1 && $b -eq 2 ]]; then ... fi

#===========
# [ ] 的写法 (繁琐且易错)
if [ "$a" -eq 1 -a "$b" -eq 2 ]; then ... fi
```

**写 Bash 脚本时：** 始终使用 `[[ ]]`。它更安全、功能更强、代码更易读。

**写通用 /bin/sh 脚本时：** 使用 `[ ]`，并务必给所有变量加上双引号，例如 `[ "$VAR" = "VAL" ]`。

**进行纯数字计算比较时：** 考虑使用 `(( ))`，例如 `if (( a > 10 )); then ...`
