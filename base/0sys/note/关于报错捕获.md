#### 利用 `$?` 检查即时错误

在 Linux 中，每个命令执行完都会返回一个状态码（0 代表成功，非 0 代表失败）

```sh
#示例
cp file.txt ./backup/
if [ $? -ne 0 ]; then
    echo "复制失败，正在记录日志..."
    exit 1
fi
```

```sh
#或者简洁的逻辑运算符:
`command`|| { echo "失败"; exit 1; }	#命令失败才执行大括号内容
`command` && echo "成功" 				#命令成功才执行
```



#### 使用 `trap` 捕获信号与异常

`trap` 可以监听脚本运行中的各种信号，最常用的是捕获 `ERR`（任何命令失败时触发）和 `EXIT`（脚本退出时触发）

```sh
#示例:脚本出错时自动报警

# 定义一个报错函数
error_handler() {
    echo "错误发生在第 $1 行，命令状态码为 $2"
}

# 捕获 ERR 信号，执行函数并传入行号和状态码
trap 'error_handler $LINENO $?' ERR

# 故意写一个错误的命令
ls /不存在的目录

```

#### 使用 `set -e` 

**严格模式** :如果你希望脚本**一旦出错立即停止运行**，不再往下执行，可以在脚本开头加上

```sh
#!/bin/bash
set -e  # 遇到任何命令返回非零值，立即退出脚本

mkdir /root/test  # 如果权限不足，脚本在这里就会直接中断
echo "这句话不会被执行"

```

<font color=red>注意：`set -e` 有局限性，它无法捕获管道命令（如 `cmd1 | cmd2`）中前一个命令的错误。此时需要加 `set -o pipefail`</font>
