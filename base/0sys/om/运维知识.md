

```sh
# 轻量工具

# 个人电脑监控工具
-- linux: netdata
-- Windows: Glances

# 服务器运行监控工具
-- 哪吒监控(dashbord,agent)	#Docker部署 

# 压力测试工具
-- 发起端:
	linux: wrk 
	windows: autocanno

# 安全
-- linux安全审计工具: Lynis 		# 检查系统漏洞和弱口令等
-- 端口检查: nmap
	nmap -sV -F <你的服务器IP>	# 在本地电脑（而非服务器上）使用 Nmap 扫描服务器的公网 IP
-- 防火墙: ufw
	sudo ufw default deny incoming  # 默认拒绝所有入站流量
    sudo ufw allow 80/tcp           # 允许 HTTP
    sudo ufw allow 443/tcp          # 允许 HTTPS
    sudo ufw allow 22/tcp           # 允许 SSH（注意安全）
    sudo ufw enable                 # 启用防火墙
    
-- 对开源组件依赖包扫描:
	例如 Python 项目：使用 pip install pip-audit 后运行 pip-audit
	
-- web应用扫描: xray			# 代码漏洞,xss,sql注入等
-- web应用防火墙(WAF): SafeLine(雷池)
-- https证书:  HTTPS 证书（现在必须用 HTTPS，可用 Let's Encrypt 免费申请）。
-- cdn 防护

# 升级
-- cpu: 50% 左右是最佳状态		# 峰值经常超过 85%，说明需要升级。
		按翻倍比例升级:（如 2核4G -> 4核8G -> 8核16G）
-- 带宽: 小型网站或纯 API 接口，通常 5M - 10M 足够
		 建议每次加 2Mbps - 5Mbps，或者配合 CDN（内容分发网络）来分担带宽

```
