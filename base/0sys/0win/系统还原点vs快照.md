#### 系统还原点

```sh
#概述
系统还原点是 Windows 操作系统的一种“快照”保护机制，允许用户在系统出现故障或软件冲突时，将系统设置、注册表和关键系统文件恢复到之前的某个稳定状态
#原理
当系统需要修改某个已被“快照”的文件时，VSS 会在修改发生前，将该原始数据块拷贝到一个专用的存储区域（差异区域）。这样，原始卷保持更新，而备份区域保留了旧数据的“影子”
#位置
还原点文件存储在每个驱动器根目录下的隐藏文件夹 System Volume Information 中

#补充
还原操作不会删除或更改照片、文档等个人数据，但会卸载还原点创建后安装的应用、驱动和更新
```

#### 快照

```sh
#概述
更像是一本“索引记录本”。创建瞬间，它只记录当时所有数据块的位置（元数据），几乎不占用额外空间。它与原始数据共享存储块
#原理
当你准备修改某个数据块时，系统先将旧数据拷贝到快照存储区，再写入新数据。此时，快照开始占用相当于“被修改部分”大小的空间
#说明
快照并不是以“文件”为单位，而是以“数据块”（Block）为单位
假设你有一个 1GB 的大型数据库文件，而你只修改了其中 1MB 的配置内容：
快照增加： 快照空间只会增加约 1MB（加上几 KB 的索引信息），而不是重新存一个 1GB 的文件	
```
