```sh
#autoruns 清理各种系统残留(服务,软件,注册表等)

#条目
Everything： 显示所有自动运行的项目。
Logon： 显示用户登录时启动的程序。
Services： 显示系统服务。
Scheduled Tasks： 显示计划任务中运行的项目。
#颜色
粉红色 (Pink)： 没有数字签名或签名无效。这是最需要关注的！这意味着该软件的开发者身份未经过微软或其他权威机构验证。
黄色 (Yellow)： 文件丢失。表示注册表中登记了这个启动项，但在对应的文件夹里找不到,你可以安全地右键删除这些黄色条目。
	--不可删的黄色： 位于 C:\Windows\System32\Drivers 或名称带有 wow64、ntoskrnl 等字样的系统项
绿色 (Green)： 与上一次扫描相比，新增加的启动项
蓝色 (Blue)： 选中的当前行
无底色（白色/黑色）： 正常的、拥有合法数字签名的软件
--------------------------
#tcpview 显示网络连接,端口占用等,包括进程地址,软件名称,厂商等
#颜色
绿色 (Green)： 新建立的连接。表示某个程序刚刚打开了一个端口或发起了一个新请求。
	--如果屏幕经常闪动绿色连接，但你并没有在操作电脑，说明有后台软件正在高频联网
黄色 (Yellow)： 状态改变。例如一个连接从“正在连接”变成了“已建立”，或者端口号发生了变化。
红色 (Red)： 已断开/删除。表示该连接刚刚关闭或进程已终止。它会闪烁红色后从列表中消失。


```



#### Local Address 含义

```sh
#Local Address（本地地址） 常见的几种写法及其含义
0.0.0.0:端口号			#监听所有IPv4地址的指定端口
127.0.0.1:端口号		#仅监听本地回环地址（loopback），只能本机自己访问，局域网/外网无法访问
192.168.0.109:端口号	#只在本机的这个局域网IP上监听 允许局域网/无线网内访问

[::]:端口号			#IPv6全地址监听
[::1]:端口号			#IPv6的本地回环地址（相当于IPv4的127.0.0.1）

# Windows IPv6的本地链路地址
#用于同一局域网内无路由器时的自动通信（类似169.254.x.x）
[fe80::xxxx:xxxx:xxxx:xxxx%16]:端口号	
-----------------------------------------

#Remote Address（远程地址） 常见的写法
0.0.0.0:* 		#表示这是一个监听端口(还没有任何客户端连接进来) 或者UDP端口(UDP本身无连接概念)
*:* 			#同上
[::]:* 			#同上

192.168.0.108:xxx	#有一个客户端(IP是192.168.0.108)正在连接到你本机的某个端口
123.45.67.89:443	#来自公网IP 123.45.67.89 的客户端正在连接你本机的某个端口
本机IP:xxxxx		   #通常是127.0.0.1 或 ::1，表示本机内部程序在互相通信
```

#### 批处理打开指定目录

新建批处理文件 test.bat，写入如下内容：

```sh
@echo off
@set LESSCHARSET=UTF8
@d:
cmd /k "cd /job/test"
```

保存。双击即可打开cmd窗口，目录`d:/job/test`

#### 批处理代替命令执行脚本

示例：使用bat文件，调用c盘某安装路径的php.exe，执行当前路径php文件

假设当前目录为`c:\home`，`php.exe`路径：`c:\install\php.exe`

```sh
新建run.bat，内容:
@ C:\install\php.exe %1

新建test.php，内容：
<php? echo "hello";

cmd下执行：
run test.php	#输出：hello

===============
#命令行传参
%1，%2，%3...	#接收
```



#### win11禁用自动更新

 ```sh
 #禁用更新
 1.打开注册表win+r ，输入regedit
 2.定位到 \HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings
 3.新建DWORD，名字：FlightSettingsMaxPauseDays，十进制值36524
 4.打开电脑->设置->windows更新，暂停更新-延长一周 那个条目，选择延长5000周
 
 #禁用windows update服务
 win+r，输入services.msc，查找windows update服务，停止服务，并设置启动方式为手动
 
 ```

#### 文件默认打开方式还原

将文件的默认打开方式还原成无默认打开方式：
  --1.开始菜单右键运行/regedit
  --2.删除HKEY_CLASSES_ROOT下需要恢复文件格式的后缀名键值文件夹、HKEY_CURRENT_USER\Software\Microsoft\windows\CurrentVersion\Explorer  \FileExts下需要恢复文件格式的后缀名键值文件夹
  --3.重启电脑

#### 设置视频文件夹默认显示方式

**手动调整模板类型**

1. **进入目标文件夹**
   例如，打开存放视频的文件夹。
2. **设置文件夹模板**
   - 右键文件夹空白处 → **“属性”** → **“自定义”** 标签。
   - 在 **“优化此文件夹以”** 下拉菜单中选择 **“常规项”**（此模板默认支持详细信息视图）。
   - 勾选 **“同时应用于子文件夹”** → 点击 **“确定”**。
