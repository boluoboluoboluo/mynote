#### 端口

##### 常见端口

```sh
#
0–1023：知名端口（Well-Known Ports），由 IANA 分配给标准服务
1024–49151：注册端口，常被应用程序使用
49152–65535：动态/私有端口，通常用于客户端临时连接
```

**重要（通常不能关闭）**

| 端口 | 协议    | 服务  | 用途说明                                  | 是否可以关闭？                           |
| ---- | ------- | ----- | ----------------------------------------- | ---------------------------------------- |
| 22   | TCP     | SSH   | 安全的远程登录（Linux/Unix 服务器最常用） | **不能关闭**（除非改端口或禁用远程管理） |
| 53   | TCP/UDP | DNS   | 域名解析（几乎所有联网设备都需要）        | **不能关闭**（除非本地不做 DNS 服务器）  |
| 80   | TCP     | HTTP  | 普通网页访问                              | **不能关闭**（如果跑网站必须开）         |
| 443  | TCP     | HTTPS | 加密网页访问（现代网站几乎全部使用）      | **不能关闭**（如果跑网站必须开）         |
| 123  | UDP     | NTP   | 网络时间同步（系统时间校准）              | **建议保留**（可关闭但时间会漂移）       |

**视情况保留（个人电脑建议关闭，服务器视需求）**

| 端口  | 协议 | 服务                | 用途说明                     | 是否可以关闭？                         |
| ----- | ---- | ------------------- | ---------------------------- | -------------------------------------- |
| 21    | TCP  | FTP（控制端口）     | 文件传输（20端口为数据端口） | **建议关闭**（极不安全，易被爆破）     |
| 23    | TCP  | Telnet              | 明文远程登录（极不安全）     | **必须关闭**（已被 SSH 完全取代）      |
| 25    | TCP  | SMTP                | 发送邮件                     | **个人电脑必须关闭**（服务器视需求）   |
| 110   | TCP  | POP3                | 接收邮件（明文）             | **建议关闭**（用 IMAP 或加密协议代替） |
| 143   | TCP  | IMAP                | 接收邮件（支持同步）         | **视需求**（不跑邮件服务器可关闭）     |
| 445   | TCP  | SMB（Microsoft-DS） | Windows 文件/打印机共享      | **个人电脑必须关闭**（勒索病毒常用）   |
| 3389  | TCP  | RDP（远程桌面）     | Windows 远程桌面             | **个人电脑必须关闭**（极易被暴力破解） |
| 3306  | TCP  | MySQL               | MySQL 数据库默认端口         | **必须关闭**（仅内网或加白名单开放）   |
| 1433  | TCP  | SQL Server          | Microsoft SQL Server         | **必须关闭**（仅内网或加白名单开放）   |
| 6379  | TCP  | Redis               | Redis 数据库                 | **必须关闭**（无密码极易被攻击）       |
| 27017 | TCP  | MongoDB             | MongoDB 数据库               | **必须关闭**（无认证极易被攻击）       |

##### 补充

```sh
#135
它是 RPC（Remote Procedure Call，远程过程调用） 服务的“调度员”，负责告诉网络上的其他设备：你想运行的某个程序具体在哪个动态端口上
1. 可以通过135 端口直接查询到你电脑的详细信息（如操作系统版本、开了哪些服务、有哪些账户名）
2. WMI 远程管理： 公司的系统管理员在自己的电脑上输入指令，通过 135 端口连接你的电脑，查询你的硬盘剩余空间或安装了哪些软件
3. 分布式组件 (DCOM)： 比如有些大型办公系统或旧款财务软件，需要调用局域网内服务器上的代码来处理数据，这时就会用到 135 端口

#说明:
涉及到系统服务,不要关闭,关闭也比较麻烦,防火墙拦截:
防火墙添加入站规则,把tcp和udp的135端口阻止
```

##### 可关闭的端口

```sh

#137,138,139端口
#这些端口统称为 NetBIOS over TCP/IP，是老式局域网通信的基础
137 (UDP): NetBIOS 名称服务。用于在局域网内通过计算机名（而不是 IP）找到对方。
138 (UDP): NetBIOS 浏览服务。用于局域网内的“网上邻居”列表显示及数据报传输。
139 (TCP): NetBIOS 会话服务。早期 Windows 用于文件和打印机共享的传输协议

#关闭方式:
打开"网络连接" 右键点击网络适配器 → 属性
取消勾选：
"Microsoft 网络的文件和打印机共享"
"Microsoft 网络客户端"
在TCP/IPv4属性 → 高级 → WINS → 禁用NetBIOS over TCP/IP
-------------------------
#关闭445端口(文件与打印共享)
1. 控制面板 -> 程序 -> 启用或关闭 Windows 功能
   找到 SMB 1.0/CIFS 文件共享支持，取消勾选
2. 按 Win+R 输入 services.msc，找到名为 Server 的服务，右键属性，将“启动类型”改为 “禁用”，并停止服务
-------------------------

#关闭7680(windows更新传递优化)
打开 设置 -> Windows 更新 -> 高级选项 找到 “传递优化”。
关闭 “允许从其他设备下载” 的开关
```
