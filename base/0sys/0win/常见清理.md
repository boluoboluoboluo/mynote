```sh

#检查系统完整性:
chkdsk C: /f
	检查和修复硬盘文件系统（比如 NTFS 结构、文件分配表、坏扇区等）的错误
	/f：修复文件系统错误（最常用）。
	/r：定位坏扇区，并尝试恢复可读数据 (固态硬盘没必要)
sfc /scannow 
	检查和修复Windows 系统文件（比如 DLL、EXE 等核心文件）的损坏或缺失
	# sfc /verifyonly → 只扫描，不修复（适合先检查）
	# sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows → 用于离线修复（比如系统进不去时，从 PE 环境运行）

#系统垃圾:
临时文件: 开始->运行: temp 和 %temp%,删除
旧日志: c:\windows\logs,下的日志
	del /f /q C:\Windows\Logs\*.log
	del /f /q C:\Windows\Logs\CBS\*.log

#软件残留:
1.卸载软件
2.开始->运行: %APPDATA% 和 %LOCALAPPDATA%,检查,删除
3.用户文档:用户目录,检查隐藏文件,及document

#服务及注册表清理:
建议使用工具 (先备份)

#日志清理:
c:\windows\system32\winevt\logs 	#不要直接删除
去事件管理器里选择删除,或者命令:
	wevtutil cl Application
	wevtutil cl System
	wevtutil cl Security
	wevtutil cl Setup
	wevtutil cl ForwardedEvents
-----------------------------

#系统优化工具参考:
第一步：分析。 使用 WizTree 或 TreeSize 扫描全盘，看看到底是谁占用了最大的空间。
第二步：卸载。 用 Revo Uninstaller 深度卸载不再使用的软件。
第三步：自启管理。 运行 Autoruns，把所有不是红色的、不认识的第三方自启动项全部关掉。
第四步：系统清理。 运行 BleachBit，勾选除了“自由空间”以外的所有选项。
第五步：Windows 更新缓存。 以管理员身份运行命令提示符，执行 Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase，这能清理掉过时的系统更新文件，释放数 GB 空间。
```
