**URL 编码**（也称为 **Percent-encoding**，百分号编码）是确保数据在互联网上传输时不被误解

URL（网址）中只允许出现 **英文字母、数字和极少数标点符号**

URL 里的特殊字符有特定含义。比如 `?` 表示参数开始，`&` 表示参数分隔。如果你搜索的内容本身就包含 `?` 或 `&`，不编码就会导致服务器解析错误	

**非 ASCII 字符**：中文、日文、甚至表情符号（Emoji）在原始 URL 标准中是不合法的

```sh
#编码的规则：
将字符转换为其 UTF-8 编码的十六进制形式，并在每个字节前加上 %

保留字符（Reserved）：有特殊用途的字符，
	--如 : / ? # [ ] @ ! $ & ' ( ) * + , ; =
	--如果它们作为数据本身出现（而不是功能符号）		#必须编码
	
未保留字符（Unreserved）：
	--字母、数字、连字符 -、下划线 _、点 .、波浪线 ~	#不需要编码
```



```sh
1.一般浏览器和表单提交的时候都会进行自动进行url编码
2.一般服务器web框架默认都会对请求url先进行url解码

#建议手动对url的数据部分进行url编码
```
