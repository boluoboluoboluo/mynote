#保存方式
1.Cookie：最早的规范，主要用于身份验证。大小限制 4KB，每次 HTTP 请求都会自动携带
2.LocalStorage：持久化存储，除非手动清除，否则永不过期。单个网站分配容量约 5MB
3.SessionStorage：会话级存储，窗口关闭即消失
4.IndexedDB：浏览器内置的非关系型数据库（NoSQL）。用于保存大量结构化数据（如离线地图、邮件附件），容量通常可达硬盘剩余空间的 80%
5.Cache API / Service Workers：专门用于存放离线资源（HTML/JS/图片）

#浏览器查看(只能查当前网站)
F12->application->storage:...

#路径:
Chrome: %LocalAppData%\Google\Chrome\User Data\Default
Edge: %LocalAppData%\Microsoft\Edge\User Data\Default

#地址栏查看:
Chrome: chrome://settings/content/all
Edge: edge://settings/content/all
