

nginx配置主要分布在 `/etc/nginx/nginx.conf`（全局配置）和 `/etc/nginx/conf.d/`（站点独立配置）中

#### 标准站点配置模板

通常在 `/etc/nginx/conf.d/your_site.conf` 创建新文件：

```nginx
server {
    listen 80;                          # 监听 80 端口 (IPv4)
    listen [::]:80;                     # 监听 80 端口 (IPv6)
    server_name example.com www.example.com; # 域名

    root /var/www/html/my_project;      # 网站根目录
    index index.php index.html;         # 默认首页文件

    # 访问日志和错误日志路径
    access_log /var/log/nginx/site_access.log;
    error_log  /var/log/nginx/site_error.log;
    
    
     # 配置 404 错误指向 /404.html
    error_page 404 /404.html;
    # 必须为这些错误页面设置一个 location，确保它们能被正确读取
    location = /404.html {
        root /var/www/html/error_pages; # 可以专门放一个目录
        internal;                        # 关键：防止用户直接访问这个页面
    }
	# 配置 500 502 503 504 错误指向 /50x.html
    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /var/www/html/error_pages;
        internal;
    }
    

    # 1. 静态资源处理
    location / {
        try_files $uri $uri/ =404;      # 找不到文件就返回 404
    }

    # 2. PHP 脚本处理 (配合 PHP-FPM)
    location ~ \.php$ {
        include snippets/fastcgi-php.conf; # 引入标准 PHP 配置
        # 根据你的 PHP 版本和 Socket 路径修改
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock; 
    }

    # 3. 禁止访问敏感文件 (如 .git 或 .htaccess)
    location ~ /\. {
        deny all;
    }
}
```

```sh
sudo nginx -t	#检测配置文件语法
```



#### 常用功能配置

##### 反向代理

```nginx
location /api/ {
    #80 端口的请求转发到内部的 3000 端口
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

##### 强制跳转 HTTPS

```nginx
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}
```

##### 开启Gzip压缩(网页加速)

在 `nginx.conf` 的 `http` 块中添加:

```nginx
gzip on;
gzip_types text/plain text/css application/json application/javascript text/xml;
```
