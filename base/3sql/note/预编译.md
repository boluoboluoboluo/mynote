```sh
普通sql执行:解析完整的sql语句,生成词法结构,再执行	# 值的内容可能会影响词法结构

	--修复:变量只能是数据

#预编译问题
需要根据传入变量解析词法,则该变量无法进行预编译:
如 order by xx	#需要根据xx的内容提前确定排序字段,从而决定是否使用索引等功能,所以预编译阶段该值不能用 ? (占位符)取代
select * from xx	#表名,不能使用占位符?取代,预编译阶段必须先确定查哪个表
```
