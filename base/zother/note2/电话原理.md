#### 手机通话原理

```sh
# 手机一直在静默监听基站信号
# 手机会定时向基站报告位置
```

```sh

# 1.拨号与信号上行（手机 ➔ 基站）
	-- '随机接入:' 
		手机在空中特定的公共频率上发送一个微小的电磁脉冲（随机接入请求），告诉基站 -> 我要
		打电话，请分配一个专属通道。
	-- 	'射频调制:' 
		手机的基带芯片将你的拨号请求和SIM卡标识（IMSI）转化为二进制数字，并利用正交频分复用（OFDM）
		等射频技术，将这些“0和1”调制到高频电磁波（如 2.1GHz 或 3.5GHz）的振幅、频率或相位上。
	--  '天线发射:' 
		手机内部的功率放大器将信号推向手机天线，电磁波以光速穿过空气，被基站的巨大板状天线接收。
		基站将其还原为数字信号。信号通过地下的光纤网络，送到电信运营商的“大脑”——核心网（Core Network）
# 2.鉴权与授权（基站 ➔ 核心网）
	-- '身份验证:' 
		核心网的数据库（5G中称为UDM，4G中称为HSS）收到请求后，不会立刻同意，而是向你的手机
		发送一个随机挑战码（RAND）。
	-- 'SIM卡芯片计算:' 
		手机把这个挑战码输入到SIM卡的内部加密芯片中，利用卡内不可读取的密钥（Ki）进行算法
		生成一个签名。 
	-- '授权开通:' 
		手机把签名发回核心网。核心网用同样的算法比对，一致则通过。这个过程确保了你的手机号没有被克隆，
		且没有欠费，正式被授权使用网络资源
# 3.寻呼与定位（寻找对方手机）
	-- '核心网查表:' 
		核心网的数据库实时记录着全球所有开机手机的“跟踪区（Tracking Area）”。它查到对方手机目前
		正在“A城市B区”活动
	-- '下发寻呼:' 
		核心网向B区范围内的所有基站发送一条指令：“全网广播，寻找手机号为XXXX的用户！”
	-- '被叫响应:' 
		这些基站同时向空中发射寻呼电磁波。对方手机在开机状态下，每隔一两秒就会“睁眼”瞅一眼空气中的
		寻呼信道。一旦看到自己的名字，它立刻向身边的基站大喊：“我在这里！”并同样完成一次上述的鉴权流程
# 4.通知振铃
	-- '建立信令连接:' 
		核心网下达指令给双方基站 -> 为这两台手机各自锁定专用的无线电控制信道。
	-- '下发振铃指令:' 
		核心网向对方手机发送一条名为 SIP: INVITE（现代4G/5G网络基于VoLTE/VoNR技术，走的是IP
		多媒体协议）的信令数据包。
	-- '手机执行:' 
		对方手机的操作系统（iOS或Android）解析了这个数据包，识别出这是一封“通话邀请”，于是调用手机
		扬声器播放铃声，并在屏幕上弹出接听界面。同时，对方手机发回一个“正在振铃”的信号，核心网收到后，也会在你
		的听筒里播放“嘟——嘟——”的回铃音。
# 5.接听与通话数据实时对接（双方接通）
	-- '信道升级:' 
		核心网立刻关闭你听筒里的“嘟嘟”声，并在两端基站之间为你们分配高优先级的专用语音数据通道
		（Dedicated Bearer）。这个通道拥有最高的通行权，即使周围几万人都在刷视频抢网速，也绝不允许卡顿你们
		的通话。
	-- '实时语音流对接（RTP协议）:' 
		手机麦克风采集声音 ➔ 语音编码芯片（如AMR-WB）将声音高压缩成一个个非常小的语音数据包 ➔ 手机天线用
		电磁波射向基站A ➔ 基站A转为光信号 ➔ 通过运营商的光纤骨干网（走 RTP 实时传输协议）一路狂飙 ➔ 传到
		对方身边的基站B。
		基站B用电磁波把数据包射向对方手机 ➔ 对方手机解码芯片还原成音频 ➔ 驱动听筒振膜发声
	-- '毫秒级同步:'
		这个全光纤加无线的传输，在全国范围内延迟通常被控制在 50毫秒到100毫秒 以内，人类耳朵几乎察觉不到，从而
		实现了实时对讲。
```

```sh
# 手机信号接收过滤:
# 全世界有几百万、几千万个基站同时在发射信号

# 过滤:
1.基站接收过滤: 	
	#距离衰减（平方反比定律）+ 地形阻挡, 阻止范围外的电磁波
2.手机天线过滤: 	
	#只感应特定频段(例如 1.8GHz - 3.5GHz)的电磁波,产生电流
3.滤波器:		  
	#只接收指定频率 (手机核心的物理硬件,它只在特定频率下才会震动,纯物理过滤，不需要任何芯片计算，不耗费CPU算力)
4.信号过滤:
	#基站发的信号混杂了多个数据,通过 时隙（Time Slot）对齐,只取特定时间片的数据,比如"每秒钟的第 0.001 秒，
	#才是发给你的数据。”
```

#### 电视原理

```sh
# 传统无线电视
[ 电视台播控中心 ] ➔ [ 全城最高点的电视发射塔 ] ──(空中无线电磁波广播)──> [ 你家屋顶的天线 ] ➔
[ 电视机 ]
-- # 特点: 全功率向空中广播

# 有线数字电视（家里安有机顶盒的模式）
[ 电视台 ] ➔ [ 省/市广电中心机房 ] ➔ [ 城市地下广电专用光纤网 ] ➔ [ 小区广电光节点 ] ➔ 
[ 同轴电缆 ] ➔ [ 家里机顶盒 ]
-- # 特点: 电视台同时把所有频道（CCTV-1到CCTV-13，地方台等上百个台）的数据，在同一时刻全部一股脑推到了你家客厅的这根线里！
-- # 广电中心机房每个频道的视频数据,分别调制在不同的物理频率上,把这上百个频率的电磁波融合成一个超级复合波
-- #这个超级复合波通过地下的广电专用光纤和电缆，就像自来水厂供水一样，源源不断地压进整个城市每一个小区的每一个家庭

# 现代网络电视 / 手机看直播（IPTV、投屏、网络App）
[ 电视台直播源 ] ➔ [ 互联网骨干网 ] ➔ [ 腾讯/爱奇艺/电信的 CDN 缓存服务器 ] ➔ [ 宽带主干线/5G核心网 ] 
➔ [ 家里路由器/5G基站 ] ➔ [ 你的智能电视/手机 ]
-- # 特定: 电视台把直播流源源不断推给网络公司的服务器机房
-- # 区别: 服务器不会主动把上百个频道的数据同时发给你。只有当你的电视开机，点击了“CCTV-5”时，你的电视才会向服务器发送一个请求数据包：“我要看5台。”
```
