

```sh
# 原理:
-- 将大文件切碎，用密码学算法生成指纹，并使用 Bencode 编码序列化为结构化文本

# 步骤:
1.数据切片: # 将文件（或多个文件组成的目录）按固定大小（如 256KB, 512KB, 4MB）切成无数个数据块（Pieces）
2.哈希计算: # 遍历每个数据块，使用 SHA-1（BT v1 协议）或 SHA-256（BT v2 协议）算法计算出该块的二进制安全散列值（20字节）
3.元数据拼接: # 所有数据块的哈希值按顺序拼接成一个超长的二进制字符串。
4.Bencode 编码: # BT 协议专用的序列化方式。将文件名、文件大小、切片大小、Tracker 服务器地址以及拼接好的哈希字符串，转换成一种平台无关的文本格式。

```

```sh
# 文件夹做种原理:
-- 在 .torrent 文件的 info 字典中,引入1个 files 列表来实现多文件映射

#示例:
# 文件夹种子的 Info 字典底层 Bencode 结构
{
    b'name': b'my_folder',          # 根文件夹名称
    b'piece length': 1048576,        # 切片大小（如 1MB）
    b'pieces': b'...',              # 所有切片的 SHA-1 哈希无缝拼接串
    b'files': [                     # 文件夹内的文件列表
        {b'length': 500000,  b'path': [b'sub_folder', b'file1.mp4']},
        {b'length': 1500000, b'path': [b'file2.txt']}
    ]
}

```
