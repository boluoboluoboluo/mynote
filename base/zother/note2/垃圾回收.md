#### 标记-清除法

```sh
# 根:
引擎维护一个绝不会销毁的对象,根可触达每一个对象属性和函数

# 1.标记阶段（Marking）：
GC 从所有的“根”开始遍历内存，把所有能走到的对象都贴上一个“活着”的标签。你的那个孤岛函数因为走不到，所以没有被贴标签

# 2.清除阶段（Sweeping）：
GC 遍历整个内存堆，发现这个函数没有“活着”的标签。

# 3.内存释放：
C++ 底层直接调用内存管理命令（如 free()），将该函数占用的内存地址标记为“空闲”，允许后续的新数据写入这里。
```

#### 分代回收

```sh
# 目的
为了不让检查过程卡顿，V8 把内存分成了新生代（New Space）和老生代（Old Space）：

# 新生代 vs 老生代:
-- 你的函数刚被创建时，处于“新生代”内存区。这个区域非常小，GC 检查得极其频繁（几毫秒到几十毫秒一次）。
-- 如果你快速开启并立刻关闭了监听，它在新生代就会被迅速抓到并释放，整个过程非常高效。
-- 如果这个监听器运行了很久（比如几分钟），它就会被晋升到“老生代”内存区，那里的回收频率就会变低，直到浏览器觉得内存紧张时才会去深度清理它。
```
