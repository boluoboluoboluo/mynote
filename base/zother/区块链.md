#### 定义

```sh
# 定义:
区块链（Blockchain），本质上就是一个“由全球所有人共同维护、任何人也无法作弊的超级公共记账本” 

# 本质:
一个开源的分布式网络程序项目
区块链的“核心客户端程序”（不含账本数据）极其精简，通常只有 几十 MB 到 100 MB 左右。它只是一个纯粹的后台核心引擎

# 特点
1.去中心化
2.不可篡改
3.公开透明
4.生而匿名

# 技术
1.P2P 点对点网络（连结全球服务器的纽带）
2.非对称加密算法（保障谁的币归谁）	#椭圆曲线加密（ECDSA）。它在技术上把“账户”变成了“公钥”，把“密码”变成了“私钥”。
3.时间戳与链式数据结构	#每一个区块在生成时，都必须包含上一个区块的密码哈希值（哈希特征）
4.PoW 共识机制 ->  PoS（质押记账）	#技术前身：亚当·巴克（Adam Back）为了防止垃圾邮件发明的 Hashcash 机制。

# 账本
账本数据没有保存在任何云端或中央服务器上，而是全量保存在全球每一个“全节点（Full Node）”的本地硬盘里。
'不同区块链的账本数据量':
	-- 比特币（BTC）账本：约 600 GB - 700 GB。比特币历史悠久，但由于每10分钟才产生一个区块，每个区块限制在1MB~4MB，所以增长很慢。一个 1TB 的普通固态硬盘就能装下它17年来的所有账本。
	-- 以太坊（ETH）全节点账本：约 1.2 TB - 2 TB 甚至更高。因为以太坊上运行着无数的智能合约和应用，数据量大得多。

# 节点数量
 -- 比特币: 截至 2026 年，在全球公共网络上可以直接被探测到并保持活跃数据中继的可达节点（Reachable Nodes）大约在 1.8 万到 2.4 万个之间 , 而算上那些隐藏在防火墙、家庭路由器或 Tor 匿名网络背后的不可达节点，全球总节点数估计在 5 万到 10 万个
 -- 以太坊: 全球活跃全节点大约在 1.4 万个 左右，主要集中在美国、德国和中国等基础设施发达的国家

# 安装使用
1.全节点方式: 安装核心程序,下载账本 # 个人用户不建议 (略)
2.轻节点/钱包方式:
	-- 在电脑上安装一个浏览器插件（如 MetaMask）或独立 App（如 Tonkeeper 电脑版）。
	-- 底层原理：这个软件非常小（几 MB）。它本身不下载账本，而是通过网络去访问那些由大公司或社区维护的“全节点”。你发起一笔转账，轻钱包把你的签名发给全节点，让全节点帮你写入区块链。这不需要消耗你任何硬盘空间，一分钟就能安装好。
	
	
```

```sh
# 身份标识
1.公钥（账号/地址） 和 私钥（密码/签名钥匙）	
 -- 公钥：身份标识，全网公开		# 哈希,比如一串长代码 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa
 -- 私钥: 解锁对公钥锁定的记账数据
2.创建方式:
 -- Trust Wallet  	# 币安维护	trustwallet.com
 -- OKX Web3 钱包 	#由主流交易所欧易团队维护。 okx.com
 -- Tonkeeper 创建钱包生成	#TON 基金会核心开发者 tonkeeper.com

# 余额
余额的本质：UTXO（未花费的交易输出）,你的钱包里显示的"余额：10 BTC"，在底层硬盘里，只是几笔"别人转给你、但你还没花出去的转账记录"。
	#举例:
	# 你钱包里有 11.2 个 BTC。在底层，并没有一个写着“11.2”的数字。它可能由三张不同面额的“支票”（UTXO）拼凑而成：
    -- 支票 A：两年前张三转给你的 10 BTC
	-- 支票 B：一年前李四转给你的 1 个 BTC
	-- 支票 C：昨天王五转给你的 0.2 BTC
	# 当你查询余额时，钱包软件只是帮你把这三张支票的金额加了起来：10+1+0.2=11.2
	
# 交易案例:
举例: 你（拥有 11.2 BTC）要去特斯拉官网，花 1.2 BTC 买一辆车。
	# 系统写交易单:
	1.输入: Input，钱从哪来		# 公钥账本余额
	2.输出 1: Output，钱去哪了		# 特斯拉地址
	3.输出 2: 找零，钱回哪去		  
    4.消费: 未指定去向		# 这就是留给矿工的手续费（佣金）
    # 盖章签名:
    输入密码，钱包用你的私钥对这张交易单进行密码学签名。这个签名证明了“这两张支票确实是本人同意花掉的”。
    # 广播:
    你的电脑把这张签好名的交易单，发送给连接的区块链节点，节点再向全球广播。
    
```

```sh
全球运行着超高算力专用矿机（如 ASIC 矿机）的服务器机房所有者。他们的本质工作是：全网抢着记账的“审计会计”

2.矿工疯狂消耗电力，让芯片去解一道极难的密码学数学题（寻找满足条件的哈希值）
3.全球几万个矿工同时在算。突然，冰岛的一个矿工率先算出了答案！他获得了这一页账本（区块）的独家记账权。

-- ps: '比特币每4年要奖励减半'

-- 中奖概率：如果你只买一台 2 万块钱的矿机放家里挖，你抢到记账权的概率可能相当于连续中三次双色球一等奖。

-- 矿工的真实利润：目前挖矿已经演变成了跨国工业。
-- 俄罗斯西伯利亚、美国德州的大型机房，拥有几万台机器，每天纯电费就要花出去 100 多万元。
```

```sh
# 挖矿计算题
-- “哈希碰撞”（Hash Collision），具体使用的是美国国家安全局发明的 'SHA-256' 算法
-- 这道题在数学上没有任何逻辑、公式或捷径可循，解题的唯一方法就是“纯暴力瞎猜” 

# 真正的比特币数学题公式：
-- SHA-256(交易数据 + 上一个区块密码哈希值 + 随机数) = 0000000000000000000...
-- 系统给出的题目是："请找出对应的随机数（Nonce），使得它们拼接在一起经过 SHA-256 算法粉碎后，吐出的乱码开头必须连续包含 19 个数字 0！"
-- 优化: 由于现代计算机恐怖的算力增长,只改随机数 可以瞬间计算出答案, 于是增加了微调:
		#新增微调,控制计算难度
		-- 交易数据后留言板微调
		-- 时间戳微调

===========================
# 矿机工作:
矿机在底层做的事情，就是把这个“随机数”从 1 试到 2，再试到 3……一直试到几万亿、几十万亿。直到碰巧有哪一个数字放进去，算出来的结果开头是一长串 0。
	
# 工作难度调整:
-- 保证全球矿机变多或变少时，依然稳定在 10 分钟出题
-- 难度动态调整（Difficulty Adjustment）：比特币代码规定，每过两周（2016个区块），系统就会统计一下过去两周大家解题的平均速度 
-- 如果大家算得太快（平均只要5分钟），系统就会自动把题目变难——比如要求乱码开头的 0 从 19 个变成 20 个
```
