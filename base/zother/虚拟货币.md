#### 交易方式

① 中心化交易所（CEX）—— 最适合新手

- **代表**：币安（Binance）、OKX（欧易）、Coinbase。
- **玩法**：就像“币圈的证券交易所”。你需要在里面绑定身份证进行实名认证（KYC）。
- **优势**：有平台担保，体验非常像炒股，买卖一键完成。
- **缺点**：你的币其实存在交易所的钱包里，如果交易所倒闭（如当年的 FTX），你的资产可能化为乌有。

② C2C / OTC 交易（法币出入金）—— 换成真钱的桥梁

- **代表**：交易所内置的 C2C 板块、Telegram 的 `@wallet`。
- **玩法**：**个人对个人交易**。你想买 USDT，平台匹配一个卖家。你通过微信、支付宝或银行卡直接转账给卖家的个人账户，卖家确认收到钱后，平台把冻结的数字货币释放到你的账户。
- **致命风险**：**“黑钱冻卡”**。如果卖家付给你的钱是电信诈骗或网络菠菜的“黑钱”，你的银行卡会被公安局立刻**远程冻结**，配合调查，过程非常麻烦。

③ 去中心化交易所（DEX）—— 匿名老手的乐园

- **代表**：Uniswap、Ston.fi（TON 链上最大交易所）。
- **玩法**：不需要实名，不需要注册账号。你只需要下载一个独立钱包（如 Tonkeeper），完全通过代码（智能合约）在链上与其他匿名用户兑换货币。
- **优势**：绝对匿名，资产完全由你手里的 12 个助记词控制，谁也抢不走。
- **缺点**：门槛极高，一旦操作失误转错地址，或者弄丢了助记词，资产永远无法找回。



#### 交易过程

```sh
币圈的通用“中间货币”是 'USDT（泰达币）'

# 交易所货币
任何交易都是成对出现的。比如你想用 USDT 买 TON，那对应的产品就叫 `TON/USDT`。

# 流程
你的现金(人民币/港币) ── [C2C市场] ──► USDT ──► 购买虚拟货币(如比特币等)
虚拟货币 ──► USDT ── [C2C市场] ──► 买家支付(微信/支付宝等)
```

#### 交易事项

```sh
# 交易所的硬性限制
全球主流交易所（如币安、OKX）规定，单笔现货交易的最低金额通常是 '5 USDT 或者是 10 USDT'（约合人民币 '36元 至 72元'）。

# C2C 卖家的限制
在交易所里用微信、支付宝找商家买 USDT 时，商家会设置一个"起售金额"。通常最低起售额是 '100元人民币'
```

#### 手续费

```sh
# C2C 充值手续费：0 元
-- 你用微信/支付宝把人民币转给商家，商家把 USDT 给你。这个过程 '交易所不收任何手续费'

# 币币交易手续费（买入/卖出）：约 0.1%
 -- 当你用 USDT 在交易所买入 TON，或者把 TON 卖回 USDT 时，交易所会抽取极其微小的佣金。
 -- '标准费率'：通常是交易金额的 '0.1%'
 -- 举个例子：你买了价值 100 元人民币的 TON 币，手续费只有 1 毛钱（0.1 元）
 
# 链上提现/转账手续费（如果你要把币转走）
如果你不想把 TON 币存在交易所，想把它转到你的 Telegram 内置钱包 或 Tonkeeper 钱包 里去玩小游戏。
这时会产生区块链的"网络矿工费（Gas Fee）"
-- 举例: TON 链的手续费非常便宜，从交易所提现一次，通常固定扣除大约 '0.01 到 0.05 枚 TON 币'（折合人民币 几毛钱到两块钱不等），无论你转账多少金额，手续费都是固定的。
```

#### 其他

```sh
# 汇率差（溢价）
通过 C2C 用人民币买 USDT 时，商家卖给你的价格通常会比国际美元汇率稍微贵一点点（'比如正常汇率 7.2，商家卖 7.25'）。这是正常的场外溢价，属于交易成本的一部分。

# 提现风控期（T+1）
为了防止洗钱，大部分交易所（尤其是 OKX 或币安）在你第一次用人民币买入 USDT 后，这笔资金会触发 '24小时或48小时内禁止提现'的保护机制。也就是说，你买完币后可以立刻在交易所里炒，但如果想把币转到 Telegram 钱包里，需要等待 1-2 天。
```
