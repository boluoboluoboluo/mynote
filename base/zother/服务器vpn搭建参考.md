

#### 操作说明

```sh
# 1.推荐厂商:
	BandwagonHost (搬瓦工)（有优质的 CN2 GIA 线路）、
	Vultr
	DigitalOcean  
	Linode

	# 选购:
	-- 周期付费:传统模式,
	-- 按小时付费(按量),以 Vultr、DigitalOcean 为代表,
		随时销毁,停止付费,ip被封,可新建(新ip)
	-- 线路:线路标注有 CN2 GIA、AS9929 或 BGP 优化
	-- 月低于 50 元  (1核1g每月封顶5美元,折合每小时大约扣 $0.007 美元)
	-- cpu:1核	#足够
	   内存:1g
	   硬盘:10~20g
	   带宽:1Gbps~2.5Gbps
	   流量:流量：每月 500 GB 到 1 TB 即可

	# 注意事项
	-- 购买时,关闭vpn,直连操作
	-- 创建和销毁服务器不扣费,使用才扣费
	-- 可使用快照功能,快速创建服务器实例
======================
# 2.连服务器
ssh name@ip -port xx
======================
# 3.脚本一键安装
当前最安全、抗封锁能力最强的是 Xray (VLESS-XTLS-Reality) 协议或 Hysteria2 协议。
直接复制以下开源社区流行的一键脚本:
	bash <(curl -Ls https://githubusercontent.com)
	# 说明:
	安装完成后，会提示你设置一个端口、用户名和密码。
	接着在浏览器输入 http://你的服务器IP:端口 
	即可进入可视化网页管理面板（X-ui），在里面可以直接一键添加 VLESS-Reality 节点。
======================
# 4.客户端连接
安装客户端: 如 v2rayN、Clash Verge 或 Shadowrocket
-- 在自建的网页面板（X-ui）中，点击“二维码”或“复制链接”
-- 打开客户端,直接扫描二维码或从剪贴板导入即可开始使用
```
