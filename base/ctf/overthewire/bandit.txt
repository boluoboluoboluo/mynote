	思路:copy到/tmp/tmpxxxx,转二进制文件,然后查看文件类型(压缩),然后不停改后缀,解压
	答案:
		cd /tmp			
		mktemp -d		#生成随机目录
		xxd -r data.txt > data.bin	#转二进制
		file data.bin		#查看类型,发现是gz压缩
		mv data.bin data.gz
		gzip -d data.gz	#解压
		重复上面步骤,注意识别解压方式gzip,bzip2,tar

level25:

		连bandit25,检查/etc/passwd,查看bandit26的shell,发现shell是/usr/bin/showtext	#不是默认的bash	
		查看/usr/bin/showtext,发现more命令	
	思路:在linux中,程序输出内容多,会使用more来分屏显示,more会暂停等待用户输入,
		而在more的状态下,可以按v进入vi编辑器,在里面可以执行系统命令
	答案:
		1.缩小终端窗口(足够小),再连ssh,然后触发more
		2.按v进入vi编辑器,执行":set shell=/bin/bash"
		3.再接着执行":shell",成功绕过限制,获得bash shell
		4.发现一个有SUID权限的bandit27-do文件	
			执行: ./bandit27-do cat /etc/bandit_pass/bandit27		#获取下一关密码
