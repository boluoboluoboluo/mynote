

**UPX** (Ultimate Packer for eXecutables) 是一款开源、跨平台的**可执行文件压缩器**。

简单来说，它的作用是将一个可执行文件（如 Linux 中的 ELF、Windows 中的 EXE 等）进行“瘦身”，使其体积大幅减小，同时在运行时能**自动解压到内存并直接执行**，用户感知不到任何差异。

```sh

#普通压缩： 
你需要手动解压成原始文件才能运行	# 如 7-Zip
#UPX 压缩： 
它会在可执行文件的头部插入一段极其精简的解压代码（Stub）。当你运行压缩后的文件时，这段代码会先在内存中把压缩的数据还原，然后跳转到程序的入口点运行。这个过程被称为 “运行时解压”。

节省磁盘空间： 压缩率通常能达到 30% - 70%，对嵌入式系统、固件或云原生微服务（减少镜像体积）非常有用
隐藏部分特征： 因为原始代码被压缩了，直接用十六进制编辑器（如 xxd）或 strings 看不到原始的字符串和逻辑。
传输优化： 减小体积意味着更快的网络下载和分发速度
	
#安装
sudo apt install upx-ucl

#压缩 
upx my_program    # 默认压缩
upx -9 my_program # 最高压缩率

upx -d my_program	#解压
upx -d 1.exe -o 2.exe	#把1.exe脱壳,写入2.exe

```
