[Nmap](https://nmap.org/)（Network Mapper）是一款开源免费的网络探测和安全审核工具

```sh
#核心功能
1.主机发现			#检测网络中哪些设备处于在线状态（如使用 Ping 扫描）
2.端口扫描			#识别目标主机上开放的 TCP/UDP 端口。
3.服务/版本探测	  #确定端口上运行的具体服务及其版本号
4.操作系统探测	  #利用指纹识别技术推断目标设备的操作系统类型
5.脚本引擎			#通过 Lua 脚本实现复杂的任务，如漏洞检测、后门扫描和高级网络发现
```



```sh
-sS 	#半开放扫描,它发送 SYN 包但不建立完整连接,最常用,速度快且隐蔽性较高
-sT 	#建立完整的三次握手。通常在用户没有原始套接字权限（如非 root 用户）时使用
-sU 	#UDP 扫描,扫描UDP 端口（如 DNS、DHCP、SNMP 等），速度通常比 TCP 扫描慢很多。
-sV 	#版本探测,探测开放端口上运行的具体服务及其版本信息
-p 		#指定扫描的端口范围 如：-p 80,443 或 -p 1-1024

nmap -sn 192.168.1/24		#Ping 扫描，仅发现存活主机，不扫描端口
nmap -O 192.168.1.100		#尝试识别目标主机的操作系统

nmap 192.168.1.100			#基础扫描，探测最常用的1000个端口
nmap -sV 192.168.1.100		#探测开放端口的服务版本

nmap -A 192.168.1.100		#综合扫描（包含OS探测、版本探测、脚本扫描和路由追踪）
```
