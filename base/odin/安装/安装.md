> windows 11系统



#### 安装环境

```sh
# 搭建起 Odin + Raylib 的开发环境
1.下载 release 版本,解压:
	-- 网站:'https://github.com/odin-lang/Odin/releases'
	-- 找到最新版本的 'Assets' -> 'odin-windows-amd64-dev-2026-10.zip'
	-- 解压到: c:\odin
2.添加'Path'环境变量: C:\odin\dist
3.终端 cmd 验证: odin version
4.vscode扩展: (可选)
	-- 在搜索框输入 Odin，安装官方的插件：Odin Language Support（它会为你提供语法高亮、代码格式化）。
5.编译运行:
	odin run . 		# 用于调试(编译+链接+运行),生成exe在window的临时目录
	odin build main.odin -file	# 当前目录生成exe,-file表示单文件模式
	odin build .	# 表示编译当前目录(有多个.odin文件的情况)
		-out:game.exe	# 指定生成文件名
		
	# 减少exe体积:
	odin build . -o:size	# 砍掉调试信息
	odin build . -o:size -lto:thin -linker:lld # 链接期全局优化 (感觉没变化?)
	
	odin run test.odin -file -debug		# 调试模式
	odin build test.odin -file -o:speed	# 开启最高级别的速度优化，并且剔除所有调试代码


```

#### 运行依赖解决方案

```sh
# windows 下需要 win sdk开发工具 和 vs c++ link环境,
# 否则运行报错!
# windows 的vs环境非常庞大臃肿,用以下方案替代:

# 访问直接由原作者维护的微软核心提取官方托管页（此为 Gist 官方稳定源）：
# mmozeiko / portable-msvc:
	-- 网站: 'https://gist.github.com/mmozeiko/7f3162ec2988e81e56d5c4e22cde9977'
	-- 右侧下载: Download ZIP
	-- 解压得到的文件 portable-msvc.py 文件放进一个干净的目录里（例如 C:\odin）
	-- 在终端中运行: python portable-msvc.py 		# 确保安装python

'C:\odin'会多出来2个目录:
	-- 'msvc'目录 就是odin运行所需的底层系统环境
	-- 'downloads'目录,删除即可

'msvc'目录:
	-- 文件 'setup_x64.bat',	# 终端打开运行,可临时将msvc添加到环境变量,用来运行odin,终端关闭失效
	
	
```

#### 运行脚本

使用 新的脚本,每次调用 `setup_x64.bat`,执行注册环境变量的方式

脚本 `start_odin.bat` 内容:

```sh
@echo off
:: 中文乱码解决
chcp 65001 >nul
:: 1. 核心黑科技：用变量记住你当前双击打开它时的【出发目录】
set "PROJECT_DIR=%cd%"

:: 2. 跑到远处的精简版 msvc 目录下
cd /d "C:\odin\msvc"

:: 3. 跨目录调用激活脚本，让它把环境变量在这个窗口里拉满
call setup_x64.bat

:: 4. 瞬间瞬移回刚才记住的【出发目录】
cd /d "%PROJECT_DIR%"

:: 5. 清理屏幕，保持清爽
cls

echo ===================================================
echo  Odin 游戏开发环境已就绪 (1.25G 纯净版已全局激活)
echo  当前目录：%cd%
echo  直接输入 [ odin run . ] 即可编译运行当前项目！
echo ===================================================
cmd /k
```

<font color=red>后续,只要运行 `start_odin.bat`,然后运行odin编译运行命令即可</font>
