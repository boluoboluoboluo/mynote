

#### 方式一 

```sh
# 说明: 使用浏览器自带功能打包,生成.crx 文件
1.地址栏输入 chrome://extentions/
2.开启开发者模式 (右上角)
3.点击`打包扩展程序`,选择扩展项目根目录(包含`manifest.json`那个文件夹)
4.打包时:
	首次打包: `私钥文件`保持空,直接打包
	非首次打包(更新):`私钥文件`选第一次打包生成的`.pem`文件,可以保证插件id不变
5.打包后,项目根目录出现2个文件:
	`.crx` 文件: 此位扩展程序包
	`.pem` 文件: 私钥文件,妥善保管(单独保存,勿泄漏),更新时需要

```



#### 方式二

```sh
# 说明: 直接打包为zip (常用)
1.进入项目根目录
2.全选里面的文件,右键'压缩为zip'
-- 压缩项目下的文件,不要包含项目根目录文件夹
	
# 补充: 此方式,每次浏览器加载扩展时,如果路径不对,插件id会发生变化

# 补充2: 上传到chrome商店后:
会根据你上传的开发者账号和项目，在云端自动为你生成一个永久固定的官方 ID
```
